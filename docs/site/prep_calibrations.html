prep_calibrations

Combine the raw pixel flats into one master flat, make a normalised copy for edge tracing, and flag bad detector pixels.

Inputs and outputs

Reads

  • raw_flats: the stack of raw flat exposures, shape (nimages, nspec, nspat).
  • Frame Table role loaded for this step: pixelflat.

Writes

| Product | Contents | |---------|----------| | flat | Combined (mean) flat, shape (nspec, nspat). | | flat_var | Propagated Poisson variance of flat. | | flat_norm | flat divided by its smooth response along dispersion. This is what trace_orders uses. | | bad_pixel_mask | Boolean mask, True for bad pixels. |

Metadata recorded: n_flats, n_bad_pixels, flat_good (every pixel had at least one usable exposure) and flat_nused_median (median number of exposures used per pixel).

QA Artifact: flat, a heatmap titled "Master flat".

How to call it

Command line

onfire reduce config.yaml --until prep_calibrations

Parameter Config

steps:
  prep_calibrations:
    sigma_clip: true         # reject outlier pixels between exposures (default true)
    sigrej: 2.0              # rejection threshold in robust sigma (default depends on image count)
    normalize_window: 101    # smoothing width along dispersion, in pixels (default 101)
    bad_pixel_sigma: 5.0     # bad-pixel threshold in robust sigma (default 5.0)
    bad_pixel_window: 5      # local smoothing width for bad pixels, in pixels (default 5)

Python

state = state.run_step("prep_calibrations", params={"normalize_window": 151})

This step always works on the whole detector; it takes no order argument.

Numerical methods and idea

This step turns several noisy flat exposures into three things later steps need: a clean flat, an estimate of its noise, and a list of pixels to distrust.

1. Combine the flats. With three or more exposures and sigma_clip on, each pixel is compared with the median of that pixel across exposures. The scatter is the robust estimate

$$ \sigma = 1.4826 \,\operatorname{median}\left|f_i - \tilde f\right|, $$

and an exposure's value is rejected where $|f_i - \tilde f| / \sigma \ge$ sigrej. Where $\sigma = 0$ nothing is rejected. If sigrej is not given it depends on the number of exposures: 1.1, 1.3, 1.6 and 1.9 for 3, 4, 5 and 6 images, and 2.0 otherwise. With fewer than three exposures no clipping is done. Non-finite values are always excluded.

The combined flat is the mean of the surviving values, and its variance treats each value's magnitude as its own Poisson variance:

$$ \bar f = \frac{\sum_i w_i f_i}{\sum_i w_i}, \qquad \operatorname{Var}(\bar f) = \frac{\sum_i w_i\,|f_i|}{\left(\sum_i w_i\right)^2}, $$

where $w_i$ is 1 for kept values and 0 for rejected ones.

2. Normalise. The flat is divided by a boxcar-smoothed copy of itself, smoothed along the dispersion axis only, with normalize_window pixels. Removing the slow spectral response while keeping the spatial structure leaves the sharp order edges that trace_orders follows.

3. Flag bad pixels. Non-finite and non-positive pixels are flagged first. The flat is then smoothed along the spatial axis with a boxcar of bad_pixel_window pixels, and any pixel whose residual from that smooth version exceeds bad_pixel_sigma times the robust scatter (median absolute deviation based, over the valid pixels) is flagged too.

def prep_calibrations(
    products: dict[str, Any],
    meta: dict[str, Any],
    params: dict[str, Any],
) -> StepResult:
    """Combine raw flats and build a detector bad-pixel mask (reduction step 1)."""
    raw = products.get("raw_flats")
    if raw is None:
        raise ValueError(
            "prep_calibrations requires a 'raw_flats' product; "
            "load raw flat exposures first"
        )
    stack = np.asarray(raw, dtype=float)
    combined, variance, good, nused = combine_flats(
        stack,
        sigma_clip=bool(params.get("sigma_clip", True)),
        sigrej=params.get("sigrej"),
    )
    norm = normalize_flat(combined, window=int(params.get("normalize_window", 101)))
    bad = build_bad_pixel_mask(
        combined,
        n_sigma=float(params.get("bad_pixel_sigma", 5.0)),
        window=int(params.get("bad_pixel_window", 5)),
    )

    figure = go.Figure(
        data=go.Heatmap(z=norm, colorscale="Viridis", colorbar={"title": "norm"})
    )
    figure.update_layout(title="Master flat", xaxis_title="spatial", yaxis_title="dispersion")

    return StepResult(
        products={
            "flat": combined,
            "flat_var": variance,
            "flat_norm": norm,
            "bad_pixel_mask": bad,
        },
        meta={
            "n_flats": int(stack.shape[0]),
            "n_bad_pixels": int(bad.sum()),
            "flat_good": bool(good.all()),
            "flat_nused_median": float(np.median(nused)),
        },
        plots={"flat": figure},
    )

def combine_flats(
    flats: np.ndarray,
    *,
    sigma_clip: bool = True,
    sigrej: float | None = None,
) -> tuple[np.ndarray, np.ndarray, np.ndarray, np.ndarray]:
    """Combine a stack of raw flat-field exposures.

    Args:
        flats: Image stack with shape ``(nimages, nspec, nspat)``.
        sigma_clip: Reject pixels deviating from the per-pixel median when at
            least three images are combined. Sigma clipping needs at least
            three images to estimate a robust scale.
        sigrej: Rejection threshold in robust sigma. Defaults to a value based
            on the number of images.

    Returns:
        ``(combined, variance, good, nused)`` where ``combined`` and
        ``variance`` are the mean image and its propagated Poisson variance,
        ``good`` is the boolean good-pixel mask of the combination, and
        ``nused`` counts the exposures contributing to each pixel.
    """
    stack = np.asarray(flats, dtype=float)
    if stack.ndim == 2:
        stack = stack[np.newaxis, :, :]
    if stack.ndim != 3:
        raise ValueError(
            f"flats must have shape (nimages, nspec, nspat), got {stack.shape}"
        )

    nimages = stack.shape[0]
    good = np.isfinite(stack)

    if sigma_clip and nimages >= 3:
        if sigrej is None:
            sigrej = _default_sigrej(nimages)
        masked = np.where(good, stack, np.nan)
        median = np.nanmedian(masked, axis=0)
        dispersion = 1.4826 * np.nanmedian(np.abs(masked - median), axis=0)
        with np.errstate(invalid="ignore", divide="ignore"):
            deviation = np.abs(stack - median) / np.where(dispersion > 0, dispersion, np.inf)
        good &= (deviation < sigrej) | (dispersion == 0)

    effective = good.astype(float)
    weight_sum = effective.sum(axis=0)
    safe_sum = np.where(weight_sum > 0, weight_sum, 1.0)
    values = np.where(good, stack, 0.0)

    combined = (values * effective).sum(axis=0) / safe_sum
    variance = (np.abs(stack) * effective**2).sum(axis=0) / safe_sum**2

    good_all = good.any(axis=0)
    nused = good.sum(axis=0)
    return combined, variance, good_all, nused

def normalize_flat(flat: np.ndarray, *, window: int = 101) -> np.ndarray:
    """Normalize a flat by its smooth spectral response.

    The response is estimated by smoothing along the dispersion axis (axis 0)
    so the spatial order structure is preserved for edge tracing.
    """
    flat = np.asarray(flat, dtype=float)
    window = max(1, min(window, flat.shape[0]))
    smooth = _boxcar_columns(flat, window)
    with np.errstate(invalid="ignore", divide="ignore"):
        norm = np.divide(flat, smooth, out=np.ones_like(flat), where=smooth != 0)
    return norm

def build_bad_pixel_mask(
    flat: np.ndarray,
    *,
    n_sigma: float = 5.0,
    window: int = 5,
    flag_nonpositive: bool = True,
) -> np.ndarray:
    """Construct a detector bad-pixel mask from a combined flat.

    Args:
        flat: Combined flat image with shape ``(nspec, nspat)``.
        n_sigma: Rejection threshold, in robust sigma, for pixels deviating
            from the locally smoothed flat.
        window: Boxcar size, in pixels along the spatial axis, for the local
            smoothing used to find outliers.
        flag_nonpositive: Also flag non-finite and non-positive pixels, which
            have no usable flat-field response.

    Returns:
        A boolean mask with the same shape as ``flat``; ``True`` marks a bad
        pixel.
    """
    flat = np.asarray(flat, dtype=float)
    bad = ~np.isfinite(flat)
    if flag_nonpositive:
        bad |= flat <= 0

    smoothed = _boxcar_rows(np.where(np.isfinite(flat), flat, 0.0), window)
    residual = flat - smoothed
    valid = ~bad & np.isfinite(residual)
    if valid.any():
        sigma = mad_std(residual[valid])
        if sigma > 0:
            bad |= np.abs(residual) > n_sigma * sigma
    return bad
