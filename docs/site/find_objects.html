find_objects

Find the spatial position of every object in every order, trace each one along dispersion, and mark the pixels around them so the sky can be fit away from the objects.

Inputs and outputs

Reads

  • science, science_ivar and science_mask from process_science.
  • order_traces from trace_orders.
  • No Frame Table role is loaded for this step.

Writes

| Product | Contents | |---------|----------| | objects | Table with one row per detected object: order, obj_id, fracpos, spat_pixpos, fwhm, box_radius, snr, rms, xmid, xscale, ncoeff, trace_coeff and masked. | | object_traces | Spatial position of every object at every dispersion row, shape (nspec, n_objects). | | object_orders | The order number of each object. | | object_box_radii | The extraction box radius of each object. | | object_skymask | Boolean image; False inside an object's box, True where the sky may be fit. |

obj_id is unique across all orders, counting in the order the objects are listed. An order without a usable edge trace is masked with the reason no order trace. An object whose trace fit fails stays in the table with its own masked flag set.

QA Artifacts: object_profiles (the spatial profile of each order) and object_traces (the traces over the science image).

How to call it

Command line

onfire reduce config.yaml --until find_objects

Parameter Config

steps:
  find_objects:
    fwhm: 3.0                  # expected object FWHM in pixels (default 3.0)
    snr_thresh: 5.0            # detection threshold on the profile S/N (default 5.0)
    obj_ncoeff: 4              # Legendre coefficients of each object's trace (default 4)
    obj_trim_edg: 1.0          # ignore peaks this many samples from an order edge (default 1.0)
    box_factor: 4.0            # extraction box radius, in units of fwhm (default 4.0)
    # max_objects_per_order: 1 # keep only the brightest N objects per order (default no limit)

Python, one order, on a State Clone:

clone = baseline.run_step("find_objects", params={"snr_thresh": 3.0}, clone=True, order=13)
fig = baseline.compare(clone, "find_objects")

With order= and an existing objects table, only that order is searched again, and the other orders keep their objects.

Numerical methods and idea

Orders are curved and slanted on the detector, so objects are searched for in a straightened copy of each order.

1. Rectify. Each order is resampled onto a uniform grid that runs from its left edge to its right edge at every row. The number of samples across is the widest order width in pixels, between 5 and 512.

2. Collapse to a profile. Along the dispersion axis, samples are iteratively rejected where they deviate from the column median by more than 5 robust sigma (using $1.4826\times\mathrm{MAD}$). The survivors are averaged into a mean spatial profile, and a quadratic baseline is subtracted so object peaks sit on a flat floor.

3. Signal-to-noise. The inverse variance image is rectified in the same way and propagated through the average, giving a S/N value for every sample of the profile.

4. Find peaks. The profile and its S/N are smoothed with a Gaussian of $\sigma = \mathrm{fwhm}/2.3548$. Local maxima that are positive and above snr_thresh in S/N are kept. Peaks within obj_trim_edg samples of an edge are discarded, and peaks closer together than $0.75\,\mathrm{fwhm}$ are thinned, keeping the brightest. If max_objects_per_order is set, only that many of the brightest remain.

5. Trace and fit. From the middle row, outward in both directions, the object's centroid is measured in a window of $\pm\mathrm{fwhm}$ pixels, and each row is allowed to move at most one pixel from the position expected from the rectified peak. The centroids are fit with a Legendre series of obj_ncoeff terms with iterative 3-sigma rejection, the same polynomial family used for the order edges.

6. Sky mask. For every object, the pixels within box_factor $\times$ fwhm of its trace are set to False in object_skymask. subtract_sky fits the sky only where the mask is True.

def find_objects(
    products: dict[str, Any],
    meta: dict[str, Any],
    params: dict[str, Any],
) -> StepResult:
    """Detect spatial object profiles and trace them per order (step 6).

    Each order is rectified along its edge traces, collapsed into a
    sigma-clipped spatial profile, and searched for peaks above the S/N
    threshold. The detected centroids are traced along dispersion and fit with
    a Legendre polynomial. Background pixels outside the object boxes are
    flagged so :func:`subtract_sky` can fit the sky around the objects.
    """
    image = products.get("science")
    if image is None:
        raise ValueError(
            "find_objects requires a 'science' product; run process_science first"
        )
    traces_product = products.get("order_traces")
    if traces_product is None:
        raise ValueError(
            "find_objects requires an 'order_traces' product; run trace_orders first"
        )
    image = np.asarray(image, dtype=float)
    nspec, nspat = image.shape
    ivar = products.get("science_ivar")
    if ivar is None:
        ivar = np.where(np.isfinite(image), 1.0, 0.0)
    ivar = np.asarray(ivar, dtype=float)
    science_mask = products.get("science_mask")
    science_mask = (
        None if science_mask is None else np.asarray(science_mask, dtype=bool)
    )

    fwhm = float(params.get("fwhm", 3.0))
    snr_thresh = float(params.get("snr_thresh", 5.0))
    ncoeff = int(params.get("obj_ncoeff", 4))
    trim_edg = float(params.get("obj_trim_edg", 1.0))
    box_factor = float(params.get("box_factor", 4.0))
    max_objects = params.get("max_objects_per_order")
    max_objects = int(max_objects) if max_objects is not None else None

    existing_table = products.get("objects")
    target_index = _target_order_index(params)
    per_order: dict[int, list[ObjectTrace]] = {}
    if target_index is not None and existing_table is not None:
        per_order = _objects_from_table(existing_table)
        indices = [target_index]
    else:
        indices = list(range(FIRE_NORDERS))

    diagnostics: dict[int, tuple[np.ndarray, np.ndarray, np.ndarray]] = {}
    masked_orders: dict[int, str] = {}
    for index in indices:
        order = int(FIRE_ORDER_NUMBERS[index])
        edges = _order_edges(traces_product, order, nspec)
        if edges is None:
            per_order[order] = []
            masked_orders[order] = "no order trace"
            continue
        left, right = edges
        detected, profile, snr, peaks = _detect_order_objects(
            image,
            ivar,
            science_mask,
            left,
            right,
            order,
            fwhm=fwhm,
            snr_thresh=snr_thresh,
            ncoeff=ncoeff,
            trim_edg=trim_edg,
            box_factor=box_factor,
            max_objects=max_objects,
        )
        per_order[order] = detected
        diagnostics[order] = (profile, snr, peaks)

    ordered_traces: list[ObjectTrace] = []
    for order in FIRE_ORDER_NUMBERS:
        ordered_traces.extend(per_order.get(int(order), []))

    rows = np.arange(nspec)
    object_traces = np.full((nspec, len(ordered_traces)), np.nan, dtype=float)
    object_skymask = np.ones((nspec, nspat), dtype=bool)
    for j, trace in enumerate(ordered_traces):
        if trace.masked:
            continue
        positions = evaluate_trace(trace.coeff, trace.xmid, trace.xscale, rows)
        object_traces[:, j] = positions
        radius = max(1.0, trace.box_radius)
        for row in range(nspec):
            centre = positions[row]
            if not np.isfinite(centre):
                continue
            lo = max(0, int(np.floor(centre - radius)))
            hi = min(nspat, int(np.ceil(centre + radius)) + 1)
            if hi > lo:
                object_skymask[row, lo:hi] = False

    table = _objects_table(ordered_traces, ncoeff)
    object_orders = np.asarray([t.order for t in ordered_traces], dtype=np.int16)
    object_box_radii = np.asarray([t.box_radius for t in ordered_traces], dtype=np.float32)

    profiles_figure = _object_profile_figure(diagnostics)
    traces_figure = _object_traces_figure(image, object_traces, object_orders)

    n_masked = int(np.asarray(table["masked"], dtype=bool).sum())
    return StepResult(
        products={
            "objects": table,
            "object_traces": object_traces,
            "object_orders": object_orders,
            "object_box_radii": object_box_radii,
            "object_skymask": object_skymask,
        },
        meta={
            "n_objects": int(len(ordered_traces)),
            "n_objects_masked": n_masked,
            "object_fwhm": fwhm,
            "object_snr_thresh": snr_thresh,
        },
        plots={"object_profiles": profiles_figure, "object_traces": traces_figure},
        masked_orders=masked_orders,
    )

def _detect_order_objects(
    image: np.ndarray,
    ivar: np.ndarray,
    mask: np.ndarray | None,
    left: np.ndarray,
    right: np.ndarray,
    order: int,
    *,
    fwhm: float,
    snr_thresh: float,
    ncoeff: int,
    trim_edg: float,
    box_factor: float,
    max_objects: int | None,
) -> tuple[list[ObjectTrace], np.ndarray, np.ndarray, np.ndarray]:
    """Detect and trace objects within one order, returning QA diagnostics."""
    nspec = image.shape[0]
    width = np.nanmax(right - left)
    if not np.isfinite(width) or width < 3:
        return [], np.array([]), np.array([]), np.array([], dtype=int)
    nsamp = int(min(512, max(5, np.ceil(width))))
    rect, spat = rectify_order(image, left, right, nsamp)
    valid = np.isfinite(rect)
    if mask is not None:
        mask_rect, _ = rectify_order(np.asarray(mask, dtype=float), left, right, nsamp)
        valid &= mask_rect > 0.5
    rect_ivar, _ = rectify_order(ivar, left, right, nsamp)
    rect_ivar = np.nan_to_num(rect_ivar, nan=0.0, posinf=0.0, neginf=0.0)

    profile, good = collapse_profile(rect, gpm=valid)
    snr = profile_snr(rect_ivar, good, profile)
    peaks, peak_snr = find_profile_peaks(
        profile,
        snr=snr,
        threshold=snr_thresh,
        fwhm=fwhm,
        trim_edg=trim_edg,
        max_objects=max_objects,
    )

    traces: list[ObjectTrace] = []
    for k, peak in enumerate(peaks):
        positions, xmid, xscale = trace_object(
            rect, spat, valid, int(peak), half_width=fwhm, maxshift=1.0
        )
        coeff, rms = fit_trace(positions, ncoeff=ncoeff)
        failed = not np.all(np.isfinite(coeff))
        centre = float(
            evaluate_trace(coeff, xmid, xscale, np.array([nspec // 2]))[0]
        ) if not failed else float(spat[nspec // 2, int(peak)])
        traces.append(
            ObjectTrace(
                order=order,
                coeff=coeff,
                xmid=xmid,
                xscale=xscale,
                rms=rms,
                fracpos=float((peak + 0.5) / nsamp),
                spat_pixpos=centre,
                fwhm=float(fwhm),
                box_radius=float(box_factor * fwhm),
                snr=float(peak_snr[k]),
                masked=failed,
            )
        )
    return traces, profile, snr, peaks

def collapse_profile(
    rect: np.ndarray,
    *,
    gpm: np.ndarray | None = None,
    ndeg: int = 2,
    sigclip: float = 5.0,
    niter: int = 10,
) -> tuple[np.ndarray, np.ndarray]:
    """Collapse a rectified order into a continuum-subtracted spatial profile.

    Pixels are sigma-clipped along the dispersion axis, the surviving samples
    are averaged into a mean spatial profile, and a low-order polynomial is
    subtracted so the object peaks sit on a flat baseline.

    Args:
        rect: Rectified order image, shape ``(nspec, nsamp)``.
        gpm: Optional good-pixel mask, same shape as ``rect``.
        ndeg: Degree of the baseline polynomial to subtract.
        sigclip: Rejection threshold in robust sigma.
        niter: Maximum number of rejection iterations.

    Returns:
        ``(profile, good)`` with the baseline-subtracted profile and the final
        good-pixel mask.
    """
    rect = np.asarray(rect, dtype=float)
    data = np.where(np.isfinite(rect), rect, np.nan)
    good = np.isfinite(rect) if gpm is None else (np.asarray(gpm, dtype=bool) & np.isfinite(rect))

    for _ in range(max(1, niter)):
        masked = np.where(good, data, np.nan)
        median = np.nanmedian(masked, axis=0)
        dispersion = 1.4826 * np.nanmedian(np.abs(masked - median), axis=0)
        with np.errstate(invalid="ignore", divide="ignore"):
            deviation = np.abs(masked - median) / np.where(dispersion > 0, dispersion, np.inf)
        new_good = good & ((deviation <= sigclip) | (dispersion == 0))
        if np.array_equal(new_good, good):
            break
        good = new_good

    npix = good.sum(axis=0)
    flux = np.nansum(np.where(good, data, 0.0), axis=0) / np.where(npix > 0, npix, 1)
    flux = np.where(npix > 0, flux, np.nan)

    nsamp = rect.shape[1]
    x = np.arange(nsamp, dtype=float)
    finite = np.isfinite(flux)
    if finite.sum() > ndeg + 1:
        coeff = np.polyfit(x[finite], flux[finite], ndeg)
        baseline = np.polyval(coeff, x)
    else:
        baseline = np.nanmedian(flux) if finite.any() else 0.0
    profile = np.where(finite, flux - baseline, np.nan)
    return profile, good

def find_profile_peaks(
    profile: np.ndarray,
    *,
    snr: np.ndarray | None = None,
    threshold: float = 5.0,
    fwhm: float = 3.0,
    min_sep_frac: float = 0.75,
    trim_edg: float = 1.0,
    max_objects: int | None = None,
) -> tuple[np.ndarray, np.ndarray]:
    """Detect object peaks in a continuum-subtracted spatial profile.

    The profile (or its S/N) is smoothed with a Gaussian matched to ``fwhm``,
    local maxima above ``threshold`` are collected, peaks within ``trim_edg``
    samples of either edge are discarded, and the survivors are thinned to a
    minimum separation of ``min_sep_frac * fwhm``.

    Returns:
        ``(peaks, peak_snr)`` arrays of sample indices and their S/N values.
    """
    profile = np.asarray(profile, dtype=float)
    nsamp = profile.size
    sigma = max(float(fwhm) / 2.3548, 0.5)
    smoothed = gaussian_filter1d(np.nan_to_num(profile, nan=0.0), sigma)

    if snr is not None:
        smoothed_snr = gaussian_filter1d(np.nan_to_num(np.asarray(snr, float), nan=0.0), sigma)
    else:
        scatter = 1.4826 * np.median(np.abs(profile[np.isfinite(profile)] - np.median(profile[np.isfinite(profile)]))) if np.isfinite(profile).any() else 0.0
        if scatter <= 0:
            scatter = float(np.nanstd(profile)) or 1.0
        smoothed_snr = smoothed / scatter

    interior = (smoothed[1:-1] > smoothed[:-2]) & (smoothed[1:-1] >= smoothed[2:])
    candidates = np.where(interior)[0] + 1
    candidates = candidates[smoothed[candidates] > 0]
    candidates = candidates[smoothed_snr[candidates] >= float(threshold)]
    candidates = candidates[
        (candidates >= trim_edg) & (candidates <= nsamp - 1 - trim_edg)
    ]

    if candidates.size == 0:
        return candidates, np.array([], dtype=float)

    min_sep = max(1.0, min_sep_frac * float(fwhm))
    order = candidates[np.argsort(-smoothed[candidates])]
    kept: list[int] = []
    for peak in order:
        if all(abs(peak - chosen) >= min_sep for chosen in kept):
            kept.append(int(peak))
    peaks = np.sort(np.asarray(kept, dtype=int))

    if max_objects is not None and peaks.size > max_objects:
        ranked = peaks[np.argsort(-smoothed[peaks])][:max_objects]
        peaks = np.sort(ranked)
    return peaks, smoothed_snr[peaks]

def trace_object(
    rect: np.ndarray,
    spat: np.ndarray,
    valid: np.ndarray,
    peak_index: int,
    *,
    half_width: float,
    maxshift: float = 1.0,
    ref_row: int | None = None,
) -> tuple[np.ndarray, float, float]:
    """Trace one object's spatial centroid along the dispersion axis.

    Args:
        rect: Rectified order image, shape ``(nspec, nsamp)``.
        spat: Detector spatial coordinate of each rectified sample.
        valid: Good-pixel mask of the rectified image.
        peak_index: Sample index of the object peak at the reference row.
        half_width: Half-width of the centroid window, in pixels.
        maxshift: Maximum centroid shift between adjacent rows, in pixels.
        ref_row: Reference dispersion row; defaults to the middle row.

    Returns:
        ``(positions, xmid, xscale)`` with the per-row centroid positions and
        the dispersion-coordinate normalization.
    """
    rect = np.asarray(rect, dtype=float)
    spat = np.asarray(spat, dtype=float)
    valid = np.asarray(valid, dtype=bool)
    nspec = rect.shape[0]
    if ref_row is None:
        ref_row = nspec // 2

    residual = _row_residual(rect, valid)
    positions = np.full(nspec, np.nan)

    def _step(row: int, expected: float) -> float:
        row_valid = valid[row] & np.isfinite(spat[row])
        lo = expected - half_width
        hi = expected + half_width
        window = row_valid & (spat[row] >= lo) & (spat[row] <= hi)
        if not window.any():
            return expected
        values = residual[row][window]
        coords = spat[row][window]
        total = values.sum()
        if total <= 0:
            return expected
        centroid = float((coords * values).sum() / total)
        return float(np.clip(centroid, expected - maxshift, expected + maxshift))

    expected = float(spat[ref_row, peak_index])
    if not np.isfinite(expected):
        expected = float(np.nanmedian(spat[ref_row]))
    positions[ref_row] = _step(ref_row, expected)
    previous = positions[ref_row]
    for row in range(ref_row + 1, nspec):
        expected = float(spat[row, peak_index]) if peak_index < spat.shape[1] else previous
        if not np.isfinite(expected):
            expected = previous
        previous = _step(row, expected)
        positions[row] = previous
    previous = positions[ref_row]
    for row in range(ref_row - 1, -1, -1):
        expected = float(spat[row, peak_index]) if peak_index < spat.shape[1] else previous
        if not np.isfinite(expected):
            expected = previous
        previous = _step(row, expected)
        positions[row] = previous

    xmid, xscale = trace_coordinate(nspec)
    return positions, xmid, xscale
