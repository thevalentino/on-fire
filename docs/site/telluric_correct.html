telluric_correct

Remove the absorption imprinted by Earth's atmosphere from the flux-calibrated spectra, using either an observed A0V standard star or a precomputed atmospheric model.

Inputs and outputs

Reads

  • wave_soln, objects, and the calibrated flux and flux_var from flux_calibrate.
  • For the Empirical Telluric Correction: standard_flux (the observed standard) and standard_true (its true spectrum on each order's grid, written by flux_calibrate).
  • For the Grid Telluric Correction: the PCA atmospheric components, either as a telluric_pca product or from the file named in telpca_path.
  • Frame Table role loaded for this step: standard.

Both corrections are computed whenever their inputs exist. One of them is then made the active result.

Writes

| Product | Contents | |---------|----------| | telluric_flux, telluric_var, telluric_ivar, telluric_mask | The corrected spectra, with one column per object, from the active method. | | telluric_transmission, telluric_wave | The transmission divided out, and the wavelength grid, from the active method. | | telluric | Table with one row per object: order, obj_id, method, rms, ncoeff and masked. | | telluric_empirical_*, telluric_grid_* | The same set of products for each method that could be computed, so both can be compared. |

Metadata recorded: telluric_method, n_objects_telluric_corrected, telluric_available_empirical and telluric_available_grid.

QA Artifacts: telluric_transmission (empirical and grid curves per object) and telluric_spectra (corrected spectra over the uncorrected ones).

How to call it

Command line

onfire reduce config.yaml --until telluric_correct

Parameter Config

steps:
  telluric_correct:
    method: auto                  # auto, empirical or grid (default auto)
    telluric_continuum_order: 6   # empirical: polynomial order of the smooth response (default 6)
    telluric_object_order: 4      # grid: polynomial order of the object continuum (default 4)
    telluric_grid_niter: 4        # grid: continuum/transmission iterations (default 4)
    # telluric_ncoeff: 8          # grid: number of PCA components to fit (default all)
    # telpca_path: telpca.fits    # grid: file holding the PCA components

With method: auto the Empirical Telluric Correction is active when a standard star is available, and otherwise the Grid Telluric Correction. Asking for a method whose inputs are missing raises ValueError.

Python, comparing the two and choosing one:

fig = baseline.compare_telluric()          # both corrections, side by side
clone = baseline.run_step("telluric_correct", params={"method": "grid"}, clone=True)
baseline.commit(clone)                     # adopt the grid correction

Choosing a method is an ordinary re-run on a State Clone followed by Commit. This step always processes all objects; it takes no order argument.

Numerical methods and idea

Both methods estimate an atmospheric transmission $T(\lambda)$ and divide the spectrum by it. Pixels are never divided by less than $T = 10^{-3}$.

Empirical (from an A0V standard). An A0V star has a nearly featureless spectrum apart from its hydrogen lines, which the template supplies. The ratio of the observed standard to that template is the smooth instrument response times the atmosphere. A robust smooth log-polynomial of order telluric_continuum_order is fit to the ratio and divided out, leaving

$$ T(\lambda) = \frac{\text{observed standard} / \text{A0V template}}{\text{smooth response}}, $$

clipped to the range $[10^{-3}, 1]$. Absolute scaling, exposure time and sampling cancel in the ratio.

Grid (from a PCA model). The atmosphere is represented by a TelPCA grid whose components linearly describe the inverse hyperbolic sine of the optical depth:

$$ \operatorname{arcsinh}\tau(\lambda) = \sum_k a_k\, C_k(\lambda), \qquad T(\lambda) = e^{-\tau(\lambda)}, $$

where $C_0$ is the model mean and the coefficients $a_k$ scale the other components. With no standard star, the object's own continuum and the transmission are fit together by alternating telluric_grid_niter times. Each pass fits a robust polynomial continuum of order telluric_object_order to the spectrum divided by the current transmission (after the first pass, using only pixels where the transmission is above 0.9, so absorption lines do not bias it), then refits the PCA coefficients by linear least squares to the spectrum divided by that continuum.

Applying. The corrected flux is $F/T$ and the variance becomes $\sigma^2/T^2$.

def telluric_correct(
    products: dict[str, Any],
    meta: dict[str, Any],
    params: dict[str, Any],
) -> StepResult:
    """Remove atmospheric absorption per order (reduction step 10).

    Two independent corrections are computed when their inputs are available:
    an empirical correction derived from an observed A0V standard star
    (``standard_flux``/``standard_true``) and a grid correction fit against a
    precomputed PCA atmospheric model (``telluric_pca``). In ``auto`` mode the
    empirical correction is committed when a standard star exists, otherwise the
    grid correction is used.

    Args:
        products: State products. Requires flux-calibrated ``flux``/``flux_var``
            arrays, ``wave_soln`` and ``objects``.
        meta: State metadata (unused).
        params: Algorithmic parameters, including ``method``
            (``auto``/``empirical``/``grid``).

    Returns:
        A :class:`StepResult` with the committed ``telluric_*`` products, every
        available candidate correction, a ``telluric`` table, and QA figures.
    """
    wave_soln = products.get("wave_soln")
    if wave_soln is None:
        raise ValueError(
            "telluric_correct requires a 'wave_soln' product; "
            "run calibrate_wavelengths first"
        )
    objects = products.get("objects")
    if objects is None:
        raise ValueError(
            "telluric_correct requires an 'objects' product; run find_objects first"
        )
    flux = products.get("flux")
    flux_var = products.get("flux_var")
    if flux is None:
        raise ValueError(
            "telluric_correct requires a 'flux' product; run flux_calibrate first"
        )
    wave_soln = np.asarray(wave_soln, dtype=float)
    flux = np.asarray(flux, dtype=float)
    flux_var = (
        np.asarray(flux_var, dtype=float)
        if flux_var is not None
        else np.full_like(flux, np.nan)
    )

    standard_observed = products.get("standard_flux")
    standard_model = products.get("standard_true")
    has_empirical = standard_observed is not None and standard_model is not None
    components = _telluric_components(products, params)
    has_grid = components is not None

    requested = str(params.get("method", "auto")).lower()
    if requested == "auto":
        if has_empirical:
            active = "empirical"
        elif has_grid:
            active = "grid"
        else:
            raise ValueError(
                "telluric_correct found neither a standard star nor a telluric "
                "PCA grid; supply 'standard_flux'/'standard_true' or "
                "'telluric_pca'/'telpca_path'"
            )
    elif requested in ("empirical", "grid"):
        if requested == "empirical" and not has_empirical:
            raise ValueError(
                "telluric_correct method 'empirical' requires "
                "'standard_flux' and 'standard_true' products"
            )
        if requested == "grid" and not has_grid:
            raise ValueError(
                "telluric_correct method 'grid' requires a 'telluric_pca' "
                "product or a 'telpca_path' parameter"
            )
        active = requested
    else:
        available = ["auto"]
        if has_empirical:
            available.append("empirical")
        if has_grid:
            available.append("grid")
        raise ValueError(
            f"unknown telluric method {requested!r}; available methods: {available}"
        )

    empirical = (
        _run_telluric_correction(
            wave_soln,
            objects,
            flux,
            flux_var,
            _empirical_correction(
                np.asarray(standard_observed, dtype=float),
                np.asarray(standard_model, dtype=float),
                params,
            ),
        )
        if has_empirical
        else None
    )
    grid = (
        _run_telluric_correction(
            wave_soln,
            objects,
            flux,
            flux_var,
            _grid_correction(flux, components, params),
        )
        if has_grid
        else None
    )
    selected = empirical if active == "empirical" else grid
    if selected is None:
        raise ValueError(

        )

    obj_ids = np.asarray(objects["obj_id"], dtype=int)
    table = Table(

            "obj_id": obj_ids.astype(np.int32),

            "masked": np.asarray(

                dtype=bool,

        },
        names=TELLURIC_COLUMNS,

        return {
            f"telluric_{name}_transmission": data["transmission"],
            f"telluric_{name}_flux": data["flux"],
            f"telluric_{name}_var": data["var"],
            f"telluric_{name}_ivar": data["ivar"],
            f"telluric_{name}_mask": data["mask"],
        }

    products_out: dict[str, Any] = {}
    if empirical is not None:
        products_out.update(_candidate("empirical", empirical))
    if grid is not None:
        products_out.update(_candidate("grid", grid))
    products_out.update(
        {
            "telluric": table,
            "telluric_wave": selected["wave"],
            "telluric_transmission": selected["transmission"],
            "telluric_flux": selected["flux"],
            "telluric_var": selected["var"],
            "telluric_ivar": selected["ivar"],
            "telluric_mask": selected["mask"],
        }
    )

        sum(1 for j in range(flux.shape[1]) if selected["mask"][:, j].any())
    )
    transmission_figure = _telluric_transmission_figure(
        wave_soln,
        objects,
        empirical["transmission"] if empirical is not None else np.full_like(flux, np.nan),
        grid["transmission"] if grid is not None else np.full_like(flux, np.nan),
    )
    spectra_figure = _telluric_spectra_figure(
        wave_soln, objects, flux, selected["flux"]
    )

    return StepResult(
        products=products_out,
        meta={
            "telluric_method": active,
            "n_objects_telluric_corrected": n_corrected,
            "telluric_available_empirical": bool(has_empirical),
            "telluric_available_grid": bool(has_grid),
        },
        plots={
            "telluric_transmission": transmission_figure,
            "telluric_spectra": spectra_figure,
        },
    )

def empirical_transmission(
    wave: np.ndarray,
    standard_flux: np.ndarray,
    a0v_flux: np.ndarray,
    *,
    continuum_order: int = 6,
    gpm: np.ndarray | None = None,
    floor: float = _TRANSMISSION_FLOOR,
) -> TelluricCorrection:
    """Derive atmospheric transmission from an observed A0V standard star.

    The ratio of the observed standard spectrum to its intrinsic A0V
    photosphere is the product of the smooth instrument response and the
    atmospheric transmission. A robust smooth continuum is divided out to
    isolate the transmission, so the absolute scaling, exposure time, and
    sampling of the observed spectrum drop out.

    Args:
        wave: Wavelength grid in Angstroms.
        standard_flux: Observed standard-star spectrum (counts or flux).
        a0v_flux: Intrinsic A0V template flux on the same wavelength grid.
        continuum_order: Polynomial order of the smooth response model.
        gpm: Optional good-pixel mask.
        floor: Lower clip applied to the transmission.

    Returns:
        The empirical :class:`TelluricCorrection`.
    """
    wave = np.asarray(wave, dtype=float)
    standard_flux = np.asarray(standard_flux, dtype=float)
    a0v_flux = np.asarray(a0v_flux, dtype=float)
    with np.errstate(invalid="ignore", divide="ignore"):
        ratio = standard_flux / a0v_flux

    good = (
        np.isfinite(ratio)
        & (ratio > 0)
        & np.isfinite(wave)
        & np.isfinite(a0v_flux)
        & (a0v_flux > 0)
    )
    if gpm is not None:
        good &= np.asarray(gpm, dtype=bool)

    continuum, _ = _robust_log_continuum(
        _normalized_log_wave(wave), ratio, order=int(continuum_order), gpm=good
    )
    with np.errstate(invalid="ignore", divide="ignore"):
        transmission = ratio / continuum
    finite = np.isfinite(transmission)
    clipped = np.clip(np.where(finite, transmission, 1.0), floor, 1.0)
    residual = (transmission - clipped)[finite & good]
    rms = float(np.sqrt(np.mean(residual**2))) if residual.size else float("nan")
    return TelluricCorrection(
        wave=wave,
        transmission=clipped,
        mask=good & finite,
        method="empirical",
        rms=rms,
    )

def pca_transmission(
    wave: np.ndarray,
    components: np.ndarray,
    coeffs: np.ndarray,
    *,
    floor: float = _TRANSMISSION_FLOOR,
) -> np.ndarray:
    """Evaluate a PCA atmospheric model as a transmission spectrum.

    The components linearly parameterize ``arcsinh(tau)`` where ``tau`` is the
    optical depth. Component row 0 is the model mean; ``coeffs`` scales
    components 1..n.

    Args:
        wave: Wavelength grid (used only for shape and validation).
        components: PCA component array of shape ``(ncomp, nwave)``.
        coeffs: PCA coefficients of length ``ncomp - 1`` or fewer.
        floor: Lower clip applied to the transmission.

    Returns:
        The model transmission on the component wavelength grid.
    """
    components = np.asarray(components, dtype=float)
    coeffs = np.asarray(coeffs, dtype=float).ravel()
    ncomp = min(coeffs.size + 1, components.shape[0])
    design = np.concatenate([[1.0], coeffs[: ncomp - 1]])
    asinh_tau = design @ components[:ncomp]
    tau = np.clip(np.sinh(asinh_tau), 0.0, None)
    return np.clip(np.exp(-tau), floor, 1.0)

def fit_telluric_grid(
    wave: np.ndarray,
    flux: np.ndarray,
    components: np.ndarray,
    *,
    object_order: int = 4,
    ncoeff: int | None = None,
    gpm: np.ndarray | None = None,
    niter: int = 4,
    absorption_threshold: float = 0.9,
) -> TelluricCorrection:
    """Jointly fit an object continuum and a TelPCA transmission to a spectrum.

    Used when no standard star is available: the smooth object continuum and the
    atmospheric transmission are fit together. Each iteration fits a robust
    polynomial continuum to ``flux / transmission``, then refits the PCA
    coefficients to ``flux / continuum``.

    Args:
        wave: Wavelength grid in Angstroms.
        flux: Flux-calibrated science spectrum.
        components: PCA component array of shape ``(ncomp, nwave)``.
        object_order: Polynomial order of the object continuum model.
        ncoeff: Number of PCA components to fit.
        gpm: Optional good-pixel mask.
        niter: Number of continuum/transmission refinement iterations.
        absorption_threshold: Transmission below which pixels are excluded from
            the continuum fit, so absorption features do not bias it.

    Returns:
        The grid :class:`TelluricCorrection`.
    """
    wave = np.asarray(wave, dtype=float)
    flux = np.asarray(flux, dtype=float)
    components = np.asarray(components, dtype=float)
    ncoeff = components.shape[0] - 1 if ncoeff is None else int(ncoeff)

    base = np.isfinite(wave) & np.isfinite(flux) & (flux > 0)
    if gpm is not None:
        base &= np.asarray(gpm, dtype=bool)

    x = _normalized_log_wave(wave)
    transmission = np.ones_like(wave)
    coeffs = np.zeros(max(1, ncoeff))
    rms = float("nan")
    mask = base.copy()
    for iteration in range(max(1, int(niter))):
        with np.errstate(invalid="ignore", divide="ignore"):
            corrected = flux / transmission
        if iteration == 0:
            continuum_gpm = base
        else:
            continuum_gpm = base & (transmission >= float(absorption_threshold))
        continuum, _ = _robust_log_continuum(
            x, corrected, order=int(object_order), gpm=continuum_gpm
        )
        with np.errstate(invalid="ignore", divide="ignore"):
            observed = flux / continuum
        coeffs, mask, rms = _fit_pca_coeffs(
            observed, components, ncoeff=ncoeff, gpm=base
        )
        transmission = pca_transmission(wave, components, coeffs)

    return TelluricCorrection(
        wave=wave,
        transmission=transmission,
        mask=mask,
        method="grid",
        rms=rms,
        coeffs=coeffs,
    )

def apply_telluric(
    wave: np.ndarray,
    flux: np.ndarray,
    correction: TelluricCorrection,
    *,
    variance: np.ndarray | None = None,
    floor: float = _TRANSMISSION_FLOOR,
) -> tuple[np.ndarray, np.ndarray | None, np.ndarray | None, np.ndarray]:
    """Divide a spectrum by an atmospheric transmission estimate.

    Args:
        wave: Wavelength grid in Angstroms.
        flux: Flux density to correct.
        correction: The transmission estimate (empirical or grid).
        variance: Optional variance of ``flux`` for propagation.
        floor: Lower clip applied to the transmission before division.

    Returns:
        ``(corrected_flux, corrected_var, corrected_ivar, mask)``. The variance
        transforms as ``var / T**2`` and the inverse variance as ``ivar * T**2``.
    """
    wave = np.asarray(wave, dtype=float)
    flux = np.asarray(flux, dtype=float)
    transmission = np.clip(correction.evaluate(wave), floor, 1.0)
    mask = np.isfinite(flux) & (transmission > 0)
    with np.errstate(invalid="ignore", divide="ignore"):
        corrected = flux / transmission
    corrected = np.where(mask, corrected, np.nan)

    if variance is None:
        return corrected, None, None, mask

    variance = np.asarray(variance, dtype=float)
    corrected_var = variance / transmission**2
    with np.errstate(invalid="ignore", divide="ignore"):
        corrected_ivar = np.where(corrected_var > 0, 1.0 / corrected_var, 0.0)
    corrected_var = np.where(mask, corrected_var, np.nan)
    corrected_ivar = np.where(mask, corrected_ivar, 0.0)
    return corrected, corrected_var, corrected_ivar, mask
