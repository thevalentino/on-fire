process_science

Flat-field the science exposures, propagate their noise, and either difference nodded pairs (A minus B) or average stare frames.

Inputs and outputs

Reads

  • raw_science: the stack of science exposures, shape (nframes, nspec, nspat).
  • flat_norm (or flat) from prep_calibrations.
  • bad_pixel_mask from prep_calibrations, if present.
  • Frame Table role loaded for this step: science.

Writes

| Product | Contents | |---------|----------| | science | The flat-fielded, combined science image. | | science_var | Its variance, propagated from photon and read noise. | | science_ivar | Inverse variance, 0 for bad pixels. | | science_mask | Boolean good-pixel mask. |

Metadata recorded: science_mode, n_science_frames, n_science_combined and n_science_bad_pixels.

QA Artifact: science, a heatmap of the combined image.

How to call it

Command line

onfire reduce config.yaml --until process_science

Parameter Config. The observing mode is a top-level key, because it also affects later steps:

mode: pair_difference     # or: stare (default pair_difference)
steps:
  process_science:
    gain: 1.0             # detector gain, electrons per count (default 1.0)
    read_noise: 0.0       # detector read noise, electrons (default 0.0)

Python

state = state.run_step("process_science", params={"mode": "stare"})

This step works on the whole detector; it takes no order argument. An unknown mode raises ValueError.

Numerical methods and idea

The two observing modes differ in how the sky background is dealt with, and that decides what this step has to do.

Flat-fielding. Each exposure is divided by the normalised flat. Pixels where the flat is non-finite or not positive are set to zero instead of producing infinities.

Noise. The variance of a flat-fielded frame pushes the photon and read noise through that division:

$$ \sigma^2_\mathrm{frame} = \frac{\max(C, 0)/g + R^2}{F^2}, $$

where $C$ is the raw counts, $g$ is gain, $R$ is read_noise and $F$ is the flat response.

Pair Differencing (mode: pair_difference). Consecutive exposures are taken as nodded pairs, frames 1 and 2, 3 and 4, and so on. Each pair is flat-fielded and subtracted, $A - B$, which cancels the thermal and OH sky emission to first order. The pair variance is $\sigma^2_A + \sigma^2_B$. The differences are averaged, and with $N$ pairs the variance of that mean is

$$ \sigma^2_\mathrm{science} = \frac{1}{N^2} \sum_{p=1}^{N} \left(\sigma^2_{A,p} + \sigma^2_{B,p}\right). $$

At least two frames are required. An odd final frame is not used.

Stare Mode (mode: stare). Each frame is flat-fielded and the frames are averaged, with the variance of the mean computed the same way. No sky is removed here, so the 2D sky model in subtract_sky has to do that work.

Masking. A pixel is good if the science value and variance are finite, the variance is positive and the pixel is not in bad_pixel_mask. The inverse variance is $1/\max(\sigma^2, 10^{-12})$ for good pixels and 0 otherwise.

def process_science(
    products: dict[str, Any],
    meta: dict[str, Any],
    params: dict[str, Any],
) -> StepResult:
    """Flat-field science frames and prepare background subtraction (step 5).

    The Parameter Config ``mode`` selects between Pair Differencing (``A - B``
    of consecutive nodded exposures, which cancels the thermal and OH sky) and
    Stare Mode (a single fixed pointing, whose sky is modeled downstream). The
    output carries a variance array propagated from detector noise.
    """
    raw = products.get("raw_science")
    if raw is None:
        raise ValueError(
            "process_science requires a 'raw_science' product; "
            "load raw science exposures first"
        )
    stack = np.asarray(raw, dtype=float)
    if stack.ndim == 2:
        stack = stack[np.newaxis, :, :]
    if stack.ndim != 3:
        raise ValueError(
            f"raw_science must have shape (nframes, nspec, nspat), got {stack.shape}"
        )

    flat = products.get("flat_norm")
    if flat is None:
        flat = products.get("flat")
    if flat is None:
        raise ValueError(
            "process_science requires a 'flat_norm' or 'flat' product; "
            "run prep_calibrations first"
        )
    flat = np.asarray(flat, dtype=float)

    gain = float(params.get("gain", 1.0))
    read_noise = float(params.get("read_noise", 0.0))
    mode = str(params.get("mode", "pair_difference")).lower()
    nframes = stack.shape[0]

    if mode == "pair_difference":
        if nframes < 2:
            raise ValueError(
                "pair differencing requires at least two science frames; "
                f"got {nframes}"
            )
        npairs = nframes // 2
        differences = np.empty((npairs, *stack.shape[1:]), dtype=float)
        variances = np.empty_like(differences)
        for pair in range(npairs):
            a = stack[2 * pair]
            b = stack[2 * pair + 1]
            differences[pair] = pair_difference(
                flat_field(a, flat), flat_field(b, flat)
            )
            variances[pair] = frame_variance(
                a, flat, gain=gain, read_noise=read_noise
            ) + frame_variance(b, flat, gain=gain, read_noise=read_noise)
        science = combine_frames(differences)
        science_var = np.nanmean(variances, axis=0) / max(1, npairs)
        ncombined = npairs
    elif mode == "stare":
        flat_frames = np.stack([flat_field(frame, flat) for frame in stack])
        science = combine_frames(flat_frames)
        frame_vars = np.stack(
            [
                frame_variance(frame, flat, gain=gain, read_noise=read_noise)
                for frame in stack
            ]
        )
        science_var = np.nanmean(frame_vars, axis=0) / max(1, nframes)
        ncombined = nframes
    else:
        raise ValueError(
            f"unknown science mode {mode!r}; expected 'pair_difference' or 'stare'"
        )

    science = np.asarray(science, dtype=float)
    science_var = np.asarray(science_var, dtype=float)
    good = np.isfinite(science) & np.isfinite(science_var) & (science_var > 0)
    bad = products.get("bad_pixel_mask")
    if bad is not None:
        good &= ~np.asarray(bad, dtype=bool)
    with np.errstate(invalid="ignore", divide="ignore"):
        ivar = np.where(
            good, 1.0 / np.maximum(science_var, 1e-12), 0.0
        )

    figure = _simple_heatmap(science, f"Science frame ({mode})")
    return StepResult(
        products={
            "science": science,
            "science_var": science_var,
            "science_ivar": ivar,
            "science_mask": good,
        },
        meta={
            "science_mode": mode,
            "n_science_frames": int(nframes),
            "n_science_combined": int(ncombined),
            "n_science_bad_pixels": int((~good).sum()),
        },
        plots={"science": figure},
    )

def flat_field(image: np.ndarray, flat: np.ndarray) -> np.ndarray:
    """Divide an exposure by the normalized flat-field response.

    Pixels where the flat response is non-positive or non-finite are set to
    zero rather than producing infinities.

    Args:
        image: Raw exposure counts.
        flat: Normalized flat-field response, same shape as ``image``.

    Returns:
        The flat-fielded exposure counts.
    """
    image = np.asarray(image, dtype=float)
    flat = np.asarray(flat, dtype=float)
    good = np.isfinite(flat) & (flat > 0) & np.isfinite(image)
    with np.errstate(invalid="ignore", divide="ignore"):
        out = np.divide(image, flat, out=np.zeros_like(image), where=good)
    return out

def frame_variance(
    counts: np.ndarray,
    flat: np.ndarray,
    *,
    gain: float = 1.0,
    read_noise: float = 0.0,
) -> np.ndarray:
    """Propagate detector noise into the flat-fielded frame variance.

    The Poisson variance of the raw counts (plus read noise) is pushed through
    the division by the flat response.

    Args:
        counts: Raw exposure counts.
        flat: Normalized flat-field response, same shape as ``counts``.
        gain: Detector gain, in electrons per count.
        read_noise: Detector read noise, in electrons.

    Returns:
        The per-pixel variance of the flat-fielded frame.
    """
    counts = np.asarray(counts, dtype=float)
    flat = np.asarray(flat, dtype=float)
    gain = max(float(gain), 1e-12)
    var_counts = np.clip(counts, 0.0, None) / gain + float(read_noise) ** 2
    safe = np.where(np.isfinite(flat) & (flat > 0), flat, 1.0)
    return var_counts / safe**2

def pair_difference(frame_a: np.ndarray, frame_b: np.ndarray) -> np.ndarray:
    """Difference two nodded exposures to cancel the sky background."""
    return np.asarray(frame_a, dtype=float) - np.asarray(frame_b, dtype=float)
