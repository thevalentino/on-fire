extinction_correct

Remove the reddening caused by Milky Way dust along the line of sight, giving the final intrinsic spectrum.

Inputs and outputs

Reads

  • coadd_wave, coadd_flux and coadd_var from coadd_orders.
  • The colour excess $E(B-V)$: either the ebv parameter, or looked up from a dust_map product at the target coordinates.
  • The target coordinates, if looking up: ra and dec parameters, or ra and dec in the state's metadata. A run through onfire reduce fills the metadata from the science FITS header, in degrees, trying the card pairs RA/DEC, RA_DEG/DEC_DEG, TELRA/TELDEC and OBJRA/OBJDEC in that order.
  • No Frame Table role is loaded for this step.

Writes

| Product | Contents | |---------|----------| | final_wave | Wavelength grid, unchanged from coadd_wave. | | final_flux | The dereddened flux density. | | final_var, final_ivar | Variance and inverse variance. | | final_mask | Boolean mask of valid samples. |

Metadata recorded: ebv, rv and n_extinction_points.

QA Artifact: extinction_correct, the dereddened spectrum over the observed one.

This is a cross-order step, like coadd_orders: if its input is Stale, the whole product is.

How to call it

Command line

onfire reduce config.yaml --until extinction_correct

Parameter Config

steps:
  extinction_correct:
    ebv: 0.05      # E(B-V) in magnitudes; skips the dust-map lookup
    rv: 3.1        # total-to-selective extinction ratio (default 3.1)
    # ra: 150.1    # target right ascension in degrees, used only for the lookup
    # dec: 2.2     # target declination in degrees, used only for the lookup

With neither ebv nor coordinates, the step raises ValueError.

Note: nothing in the pipeline currently supplies a dust_map. Without one, the lookup raises ValueError, so for a command-line reduction set ebv yourself in the Parameter Config. To use a lookup from Python, put a table with ra, dec and ebv columns into state.products["dust_map"].

Python

clone = baseline.run_step("extinction_correct", params={"ebv": 0.03, "rv": 3.1}, clone=True)
fig = baseline.compare(clone, "extinction_correct")

This step takes no order argument.

Numerical methods and idea

Dust between us and the target absorbs and scatters light more strongly at shorter wavelengths. The step reverses that with a standard extinction law and the amount of dust along the line of sight.

1. Amount of dust. $E(B-V)$ is taken from the ebv parameter if it is given. Otherwise it is read from the dust map as the value of the nearest catalogue entry, using a plain squared difference in right ascension and declination. This is not an angular distance, so it is only reliable away from the poles and for a map that is dense near the target.

2. Extinction law. The Fitzpatrick (1999) law gives the extinction relative to the V band,

$$ \frac{A(\lambda)}{A(V)} = a(x) + \frac{b(x)}{R_V}, \qquad x = \frac{10^4}{\lambda\,[\text{\AA}]}, $$

with $A(V) = R_V\, E(B-V)$. The code implements the infrared, optical and ultraviolet branches of the law; wavelengths longer than about 9100 Å ($x \le 1.1$) use the infrared branch.

3. Correct. The flux is multiplied by the factor

$$ 10^{\,0.4\,A(\lambda)}, $$

and the variance by the square of that factor. A sample is valid where the flux is finite and the factor is positive.

def extinction_correct(
    products: dict[str, Any],
    meta: dict[str, Any],
    params: dict[str, Any],
) -> StepResult:
    """Correct the coadded spectrum for Milky Way dust extinction (step 12).

    The colour excess ``E(B-V)`` is taken from the explicit ``ebv`` Parameter
    Config override when present, and otherwise queried from a local dust map
    (``dust_map`` product) at the target coordinates. The Fitzpatrick (1999)
    law dereddens the flux to intrinsic astrophysical values.

    Args:
        products: State products. Requires the ``coadd_wave``/``coadd_flux``
            products produced by :func:`coadd_orders`.
        meta: State metadata; may carry ``ra``/``dec`` coordinates.
        params: Algorithmic parameters: ``ebv``, ``rv``, ``ra``, ``dec``.

    Returns:
        A :class:`StepResult` with the ``final_*`` intrinsic spectrum products.
    """
    wave = products.get("coadd_wave")
    flux = products.get("coadd_flux")
    if wave is None or flux is None:
        raise ValueError(
            "extinction_correct requires 'coadd_wave' and 'coadd_flux' products; "
            "run coadd_orders first"
        )
    wave = np.asarray(wave, dtype=float)
    flux = np.asarray(flux, dtype=float)
    variance = products.get("coadd_var")
    variance = np.asarray(variance, dtype=float) if variance is not None else None

    ebv = params.get("ebv")
    if ebv is None:
        ra = params.get("ra", meta.get("ra"))
        dec = params.get("dec", meta.get("dec"))
        catalog = products.get("dust_map")
        if ra is None or dec is None:
            raise ValueError(
                "extinction_correct needs an 'ebv' override or 'ra'/'dec' "
                "coordinates to query the dust map"
            )
        ebv = query_ebv(float(ra), float(dec), catalog=catalog)
    ebv = float(ebv)
    rv = float(params.get("rv", RV_DEFAULT))

    intrinsic, out_var, out_ivar, mask = deredden_spectrum(
        wave, flux, ebv, rv=rv, variance=variance
    )
    figure = _extinction_figure(wave, intrinsic, flux)
    n_points = int(np.asarray(mask, dtype=bool).sum())
    return StepResult(
        products={
            "final_wave": wave,
            "final_flux": intrinsic,
            "final_var": out_var if out_var is not None else np.full_like(flux, np.nan),
            "final_ivar": out_ivar if out_ivar is not None else np.zeros_like(flux),
            "final_mask": np.asarray(mask, dtype=bool),
        },
        meta={
            "ebv": ebv,
            "rv": rv,
            "n_extinction_points": n_points,
        },
        plots={"extinction_correct": figure},
    )

def query_ebv(
    ra: float,
    dec: float,
    *,
    catalog: Table | None = None,
) -> float:
    """Return the ``E(B-V)`` at target coordinates from a local dust map.

    Args:
        ra: Right ascension in degrees.
        dec: Declination in degrees.
        catalog: A local dust map with ``ra``, ``dec`` and ``ebv`` columns. When
            ``None`` no map is available and this is an error.

    Returns:
        The colour excess of the nearest catalog entry.

    Raises:
        ValueError: If no dust map was supplied.
    """
    if catalog is None:
        raise ValueError(
            "no dust map available to query E(B-V); pass 'catalog' or set the "
            "'ebv' override in the Parameter Config"
        )
    catalog_ra = np.asarray(catalog["ra"], dtype=float)
    catalog_dec = np.asarray(catalog["dec"], dtype=float)
    catalog_ebv = np.asarray(catalog["ebv"], dtype=float)
    squared = (catalog_ra - float(ra)) ** 2 + (catalog_dec - float(dec)) ** 2
    return float(catalog_ebv[int(np.argmin(squared))])

def extinction_factor(
    wave: np.ndarray,
    ebv: float,
    rv: float = RV_DEFAULT,
) -> np.ndarray:
    """Return the multiplicative dereddening factor ``10**(0.4 * A(lambda))``."""
    return np.power(10.0, _FACTOR_SCALE * fitzpatrick99(wave, ebv=ebv, rv=rv))

def deredden_spectrum(
    wave: np.ndarray,
    flux: np.ndarray,
    ebv: float,
    *,
    rv: float = RV_DEFAULT,
    variance: np.ndarray | None = None,
) -> tuple[np.ndarray, np.ndarray | None, np.ndarray | None, np.ndarray]:
    """Correct a spectrum for Galactic dust extinction.

    Args:
        wave: Wavelength grid in Angstroms.
        flux: Observed flux density.
        ebv: Colour excess ``E(B-V)`` in magnitudes.
        rv: Total-to-selective extinction ratio ``R_V``.
        variance: Optional variance of ``flux`` for propagation.

    Returns:
        ``(flux, var, ivar, mask)`` with the intrinsic flux and variance. The
        variance transforms as ``var * factor**2`` and the inverse variance as
        ``ivar / factor**2``.
    """
    wave = np.asarray(wave, dtype=float)
    flux = np.asarray(flux, dtype=float)
    factor = extinction_factor(wave, ebv, rv=rv)
    mask = np.isfinite(flux) & (factor > 0)
    corrected = np.where(mask, flux * factor, np.nan)

    if variance is None:
        return corrected, None, None, mask

    variance = np.asarray(variance, dtype=float)
    corrected_var = variance * factor**2
    with np.errstate(invalid="ignore", divide="ignore"):
        corrected_ivar = np.where(corrected_var > 0, 1.0 / corrected_var, 0.0)
    corrected_var = np.where(mask, corrected_var, np.nan)
    corrected_ivar = np.where(mask, corrected_ivar, 0.0)
    return corrected, corrected_var, corrected_ivar, mask
