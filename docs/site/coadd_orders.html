coadd_orders

Splice the calibrated spectra of the individual orders into one continuous spectrum, combining the overlaps by inverse-variance weighting.

Inputs and outputs

Reads

  • wave_soln from calibrate_wavelengths and objects from find_objects.
  • The spectra to combine: telluric_flux, telluric_var and telluric_mask from telluric_correct if present, otherwise flux, flux_var and flux_mask from flux_calibrate.
  • No Frame Table role is loaded for this step.

Writes

| Product | Contents | |---------|----------| | coadd_wave | Wavelength grid of the combined spectrum, in Angstroms. | | coadd_flux, coadd_var, coadd_ivar | Flux density, variance and inverse variance. | | coadd_mask | Boolean mask of valid samples. |

Metadata recorded: n_coadd_orders, n_coadd_points and coadd_obj_id.

QA Artifact: coadd_orders, the combined spectrum with its uncertainty.

This step combines every order into one product, so it is a cross-order step: if any order is Stale, the whole coadd is Stale and cannot be trimmed order by order at Commit.

How to call it

Command line

onfire reduce config.yaml --until coadd_orders

Parameter Config

steps:
  coadd_orders:
    # obj_id: 3     # combine only this object (default: the highest-S/N object of each order)

Python

clone = baseline.run_step("coadd_orders", clone=True)
fig = baseline.compare(clone, "coadd_orders")

This step takes no order argument.

Choosing the object. By default one object is taken from each order, the one with the highest S/N in the objects table. Giving obj_id restricts the candidates to that one object. Because find_objects numbers objects uniquely across all orders, a given obj_id belongs to a single order, so the coadd then contains only that order. To verify: whether that is the intended use of obj_id.

Numerical methods and idea

Neighbouring echelle orders overlap slightly in wavelength, so the same part of the spectrum is measured twice with different noise. The step merges all orders onto one wavelength grid and weights each measurement by how well it is known.

  1. For each order, samples with a non-finite wavelength or flux, a masked sample, or a non-positive variance are dropped. Each remaining sample gets the weight $w = 1/\sigma^2$.
  2. The output grid is regular, from the shortest to the longest wavelength present, with a step equal to the finest median pixel spacing among the orders.
  3. Every sample is assigned to the bin containing its wavelength. No resampling or interpolation is done. The samples are used as measured.
  4. In each bin the combined flux, variance and inverse variance are

$$ \bar f = \frac{\sum_i w_i f_i}{\sum_i w_i}, \qquad \sigma^2 = \frac{1}{\sum_i w_i}, \qquad \text{ivar} = \sum_i w_i . $$

Bins that received no samples are left out of the output, so coadd_wave is not necessarily a gapless grid.

If a variance array is missing, every sample is weighted equally.

def coadd_orders(
    products: dict[str, Any],
    meta: dict[str, Any],
    params: dict[str, Any],
) -> StepResult:
    """Splice and coadd overlapping calibrated orders (reduction step 11).

    The best object of every order (highest S/N, or the one matching
    ``params['obj_id']``) is taken from the telluric-corrected spectra when
    available and otherwise from the flux-calibrated spectra, then combined into
    a single continuous 1D spectrum spanning the full FIRE range.

    Args:
        products: State products. Requires ``wave_soln``, ``objects`` and a
            flux-calibrated spectra product (``telluric_flux``/``flux``).
        meta: State metadata (unused).
        params: Algorithmic parameters, including an optional ``obj_id`` target.

    Returns:
        A :class:`StepResult` with the 1D ``coadd_*`` products and a QA figure.
    """
    wave_soln = products.get("wave_soln")
    objects = products.get("objects")
    if wave_soln is None or objects is None:
        raise ValueError(
            "coadd_orders requires 'wave_soln' and 'objects' products; "
            "run calibrate_wavelengths and find_objects first"
        )
    flux = products.get("telluric_flux")
    flux_var = products.get("telluric_var")
    flux_mask = products.get("telluric_mask")
    if flux is None:
        flux = products.get("flux")
        flux_var = products.get("flux_var")
        flux_mask = products.get("flux_mask")
    if flux is None:
        raise ValueError(
            "coadd_orders requires a flux-calibrated spectra product "
            "('telluric_flux' or 'flux'); run flux_calibrate first"
        )
    wave_soln = np.asarray(wave_soln, dtype=float)
    flux = np.asarray(flux, dtype=float)
    flux_var = (
        np.asarray(flux_var, dtype=float) if flux_var is not None else None
    )
    flux_mask = (
        np.asarray(flux_mask, dtype=bool) if flux_mask is not None else None
    )

    obj_id = params.get("obj_id")
    obj_id = int(obj_id) if obj_id is not None else None
    selected = _select_order_object(objects, obj_id=obj_id)

    waves: list[np.ndarray] = []
    fluxes: list[np.ndarray] = []
    variances: list[np.ndarray] = []
    masks: list[np.ndarray] = []
    contributing: set[int] = set()
    for index, order in enumerate(FIRE_ORDER_NUMBERS):
        order = int(order)
        column = selected.get(order)
        if column is None:
            continue
        wave = wave_soln[:, index]
        segment_flux = flux[:, column]
        if not np.any(np.isfinite(segment_flux)):
            continue
        waves.append(wave)
        fluxes.append(segment_flux)
        if flux_var is not None:
            variances.append(flux_var[:, column])
        if flux_mask is not None:
            masks.append(flux_mask[:, column])
        contributing.add(order)

    coadd = coadd_order_spectra(
        waves,
        fluxes,
        variances if flux_var is not None else None,
        masks if flux_mask is not None else None,
    )
    figure = _coadd_figure(coadd)
    return StepResult(
        products={
            "coadd_wave": coadd.wave,
            "coadd_flux": coadd.flux,
            "coadd_var": coadd.var,
            "coadd_ivar": coadd.ivar,
            "coadd_mask": coadd.mask,
        },
        meta={
            "n_coadd_orders": len(contributing),
            "n_coadd_points": int(coadd.npoints),
            "coadd_obj_id": obj_id,
        },
        plots={"coadd_orders": figure},
    )

def _select_order_object(
    objects: Table,
    *,
    obj_id: int | None,
) -> dict[int, int]:
    """Map order number to the best (highest S/N) object column for coaddition."""
    orders = np.asarray(objects["order"], dtype=int)
    if "snr" in objects.colnames:
        snr = np.asarray(objects["snr"], dtype=float)
    else:
        snr = np.ones(len(objects), dtype=float)
    if obj_id is not None and "obj_id" in objects.colnames:
        candidates = np.where(np.asarray(objects["obj_id"], dtype=int) == int(obj_id))[0]
    else:
        candidates = np.arange(len(objects))
    best: dict[int, int] = {}
    for column in candidates:
        order = int(orders[column])
        if order not in best or snr[column] > snr[best[order]]:
            best[order] = int(column)
    return best

def coadd_order_spectra(
    waves: list[np.ndarray],
    fluxes: list[np.ndarray],
    variances: list[np.ndarray] | None = None,
    masks: list[np.ndarray] | None = None,
) -> CoaddedSpectrum:
    """Splice and inverse-variance weight overlapping order spectra.

    Args:
        waves: One wavelength grid per order, in Angstroms.
        fluxes: One flux density array per order.
        variances: Optional variance array per order. When omitted every sample
            is weighted equally.
        masks: Optional good-sample mask per order.

    Returns:
        The :class:`CoaddedSpectrum` on a common wavelength grid.

    Raises:
        ValueError: If the segment lists have differing lengths.
    """
    if not (len(waves) == len(fluxes)):
        raise ValueError("waves and fluxes must have the same number of segments")
    if variances is not None and len(variances) != len(waves):
        raise ValueError("variances must have one entry per wavelength segment")
    if masks is not None and len(masks) != len(waves):
        raise ValueError("masks must have one entry per wavelength segment")

    norders = len(waves)
    all_wave: list[np.ndarray] = []
    all_flux: list[np.ndarray] = []
    all_weight: list[np.ndarray] = []
    clean_waves: list[np.ndarray] = []
    for i, (wave, flux) in enumerate(zip(waves, fluxes)):
        wave = np.asarray(wave, dtype=float)
        flux = np.asarray(flux, dtype=float)
        good = np.isfinite(wave) & np.isfinite(flux)
        if masks is not None:
            good &= np.asarray(masks[i], dtype=bool)
        if variances is not None:
            var = np.asarray(variances[i], dtype=float)
            positive = np.isfinite(var) & (var > 0)
            good &= positive
            weight = np.where(positive, 1.0 / np.where(positive, var, 1.0), 0.0)
        else:
            weight = np.ones_like(wave)
        if not good.any():
            continue
        clean_waves.append(wave[good])
        all_wave.append(wave[good])
        all_flux.append(flux[good])
        all_weight.append(weight[good])

    if not all_wave:
        empty = np.array([], dtype=float)
        return CoaddedSpectrum(
            wave=empty,
            flux=empty.copy(),
            var=empty.copy(),
            ivar=empty.copy(),
            mask=np.array([], dtype=bool),
            norders=norders,
            npoints=0,
        )

    step = _grid_step(clean_waves) or 1.0
    wave_flat = np.concatenate(all_wave)
    flux_flat = np.concatenate(all_flux)
    weight_flat = np.concatenate(all_weight)

    wave_min = float(wave_flat.min())
    wave_max = float(wave_flat.max())
    edges = np.arange(wave_min, wave_max + 1.5 * step, step)
    nbin = max(1, edges.size - 1)
    centers = edges[:-1] + 0.5 * step

    index = np.digitize(wave_flat, edges) - 1
    valid = (index >= 0) & (index < nbin)
    index = np.clip(index, 0, nbin - 1)

    summed_weight = np.bincount(index[valid], weights=weight_flat[valid], minlength=nbin)
    summed_flux = np.bincount(
        index[valid], weights=(flux_flat * weight_flat)[valid], minlength=nbin
    )

    occupied = summed_weight > 0
    wave_out = centers[occupied]
    ivar_out = summed_weight[occupied]
    with np.errstate(invalid="ignore", divide="ignore"):
        flux_out = summed_flux[occupied] / summed_weight[occupied]
        var_out = 1.0 / summed_weight[occupied]
    mask = np.isfinite(flux_out) & (ivar_out > 0)
    return CoaddedSpectrum(
        wave=wave_out,
        flux=flux_out,
        var=var_out,
        ivar=ivar_out,
        mask=mask,
        norders=norders,
        npoints=int(occupied.sum()),
    )
