trace_orders

Locate and follow the left and right spatial edges of each of the 21 echelle orders (11 to 31) on the flat, and fit each edge with a smooth curve.

Inputs and outputs

Reads

  • flat_norm (or flat if no normalised flat exists): the combined flat from prep_calibrations, shape (nspec, nspat).
  • Frame Table role loaded for this step: pixelflat.

Writes

| Product | Contents | |---------|----------| | order_traces | Table with one row per order: order, left_cen, right_cen, left_coeff, right_coeff, xmid, xscale, rms_left, rms_right, masked. | | edge_traces | Image of shape (nspec, 2 * 21) with each edge's fitted spatial position per row. |

QA Artifact: edge_traces, the edges overlaid on the flat.

An order whose edge fit fails is flagged in the Order Mask with the reason edge trace fit failed; the other orders are unaffected.

How to call it

Command line

onfire reduce config.yaml --until trace_orders

Parameter Config

steps:
  trace_orders:
    ncoeff: 5       # number of polynomial coefficients per edge (default 5)
    maxshift: 3.0   # largest row-to-row edge movement, in pixels (default 3.0)

Python, one order only, on a State Clone:

clone = baseline.run_step("trace_orders", params={"ncoeff": 6}, clone=True, order=13)
fig = baseline.compare(clone, "trace_orders")

With order= set and an existing order_traces product, only that order is re-traced and every other order keeps its previous fit. An order outside 11 to 31 raises ValueError.

Numerical methods and idea

The goal is two smooth curves per order, one for the left edge and one for the right, that later steps use to know where each order sits on the detector.

1. Find edges at the reference row. The flat is collapsed along dispersion (median over rows) and smoothed with a boxcar. The peak of this spatial profile near each expected order position is taken as the order centre. The left edge is the strongest rising spatial gradient between the previous order and the centre. The right edge is the strongest falling gradient between the centre and the next order.

2. Follow each edge along dispersion. Starting from the reference row (the middle of the detector) and working outward in both directions, each edge position is recentred row by row. The new position is the centroid of the positive part of the spatial gradient within maxshift pixels of the position in the adjacent row. For the left edge the gradient is used as is, and for the right edge its sign is flipped, so both edges look like a rising edge to the centroid.

3. Fit a smooth curve. With the row coordinate rescaled to $x \in [-1, 1]$,

$$ x = \frac{\text{row} - x_\mathrm{mid}}{x_\mathrm{scale}}, \qquad x_\mathrm{mid} = \frac{n_\mathrm{spec} - 1}{2}, $$

each tracked edge $y(x)$ is fit with a Legendre series of ncoeff terms,

$$ y(x) \approx \sum_{k=0}^{\mathrm{ncoeff}-1} c_k\, P_k(x), $$

by ordinary least squares over the rows where the trace is finite. The reported rms_left and rms_right are the root-mean-square residuals of the fit. An edge with fewer finite rows than coefficients is not fit and masks its order.

To verify: the expected order positions are the fixed fractional positions stored for FIRE (FIRE_ORDER_SPAT_POS); this page has not checked how those values were derived.

def trace_orders(
    products: dict[str, Any],
    meta: dict[str, Any],
    params: dict[str, Any],
) -> StepResult:
    """Trace the left and right spatial edges of orders 11-31 (reduction step 2).

    When ``params['order']`` targets a single order and an existing
    ``order_traces`` product is present, only that order is re-traced; all other
    orders keep their previous fits.
    """
    flat = products.get("flat_norm")
    if flat is None:
        flat = products.get("flat")
    if flat is None:
        raise ValueError(
            "trace_orders requires a 'flat_norm' or 'flat' product; "
            "run prep_calibrations first"
        )
    flat = np.asarray(flat, dtype=float)
    nspec = flat.shape[0]
    ncoeff = int(params.get("ncoeff", 5))
    maxshift = float(params.get("maxshift", 3.0))
    ref_row = (nspec - 1) // 2
    xmid, xscale = trace_coordinate(nspec)

    left0, right0, _ = detect_order_edges(flat, FIRE_ORDER_SPAT_POS)
    gradient = np.gradient(flat, axis=1)

    existing_table = products.get("order_traces")
    target = params.get("order")
    target_index: int | None = None
    if target is not None:
        matches = np.where(FIRE_ORDER_NUMBERS == int(target))[0]
        if matches.size == 0:
            raise ValueError(f"order {target} is not a FIRE echelle order 11-31")
        target_index = int(matches[0])

    coefficients: list[np.ndarray | None] = [None] * (2 * FIRE_NORDERS)
    edge_rms: list[float] = [float("nan")] * (2 * FIRE_NORDERS)
    reusing = target_index is not None and existing_table is not None
    if reusing:
        for order, (left_coeff, right_coeff, left_rms, right_rms) in _existing_entries(
            existing_table
        ).items():
            index = int(np.where(FIRE_ORDER_NUMBERS == order)[0][0])
            coefficients[2 * index] = left_coeff
            coefficients[2 * index + 1] = right_coeff
            edge_rms[2 * index] = left_rms
            edge_rms[2 * index + 1] = right_rms

    indices = [target_index] if reusing else list(range(FIRE_NORDERS))
    starts: list[float] = []
    signs: list[float] = []
    slot_of_local: list[int] = []
    for index in indices:
        for side, seed in ((0, left0[index]), (1, right0[index])):
            slot_of_local.append(2 * index + side)
            starts.append(float(seed))
            signs.append(1.0 if side == 0 else -1.0)

    tracked = trace_columns(
        gradient, np.asarray(starts), np.asarray(signs), maxshift=maxshift, ref_row=ref_row
    )
    fitted, rms = fit_edge_traces(tracked, ncoeff=ncoeff, ref_row=ref_row)
    for local, slot in enumerate(slot_of_local):
        coefficients[slot] = fitted[local]
        edge_rms[slot] = rms[local]

    table = _blank_trace_table(ncoeff)
    edge_image = np.full((nspec, 2 * FIRE_NORDERS), np.nan, dtype=float)
    rows = np.arange(nspec)
    masked_orders: dict[int, str] = {}
    for index, order in enumerate(FIRE_ORDER_NUMBERS):
        left_coeff = coefficients[2 * index]
        right_coeff = coefficients[2 * index + 1]
        table["order"][index] = order
        table["xmid"][index] = xmid
        table["xscale"][index] = xscale
        if left_coeff is None or right_coeff is None or not (
            np.all(np.isfinite(left_coeff)) and np.all(np.isfinite(right_coeff))
        ):
            table["masked"][index] = True
            masked_orders[int(order)] = "edge trace fit failed"
            continue
        left_positions = evaluate_edge_trace(left_coeff, xmid, xscale, rows)
        right_positions = evaluate_edge_trace(right_coeff, xmid, xscale, rows)
        edge_image[:, 2 * index] = left_positions
        edge_image[:, 2 * index + 1] = right_positions
        table["left_coeff"][index] = left_coeff
        table["right_coeff"][index] = right_coeff
        table["left_cen"][index] = left_positions[ref_row]
        table["right_cen"][index] = right_positions[ref_row]
        table["rms_left"][index] = edge_rms[2 * index]
        table["rms_right"][index] = edge_rms[2 * index + 1]
        table["masked"][index] = False

    figure = _edge_figure(flat, edge_image)
    n_masked = int(table["masked"].sum())
    return StepResult(
        products={"order_traces": table, "edge_traces": edge_image},
        meta={
            "n_orders": FIRE_NORDERS,
            "n_orders_traced": int(FIRE_NORDERS - n_masked),
            "n_orders_masked": n_masked,
            "ncoeff": ncoeff,
        },
        plots={"edge_traces": figure},
        masked_orders=masked_orders,
    )

def detect_order_edges(
    flat: np.ndarray,
    order_spat_pos: np.ndarray,
    *,
    profile_window: int = 7,
) -> tuple[np.ndarray, np.ndarray, np.ndarray]:
    """Locate the left and right spatial edges of each echelle order.

    The order centres are found as peaks of the dispersion-collapsed spatial
    profile, refined from the expected fractional order positions. Each left
    edge is then the strongest rising spatial gradient between the previous
    order and the centre, and each right edge the strongest falling gradient
    between the centre and the next order.

    Args:
        flat: Combined flat with shape ``(nspec, nspat)``.
        order_spat_pos: Expected fractional spatial position of each order.
        profile_window: Boxcar size used to smooth the collapsed profile.

    Returns:
        ``(left, right, centers)`` arrays of pixel positions at the reference
        row, all ordered to match ``order_spat_pos``.
    """
    flat = np.asarray(flat, dtype=float)
    if flat.ndim != 2:
        raise ValueError("flat must be 2D")
    _, nspat = flat.shape

    expected = np.asarray(order_spat_pos, dtype=float) * (nspat - 1)
    profile = boxcar_1d(np.nanmedian(flat, axis=0), profile_window)
    gradient = np.gradient(profile)

    centers = np.empty(expected.size, dtype=float)
    for i, center in enumerate(expected):
        half = _search_half(i, expected, nspat)
        lo = int(max(0, np.floor(center - half)))
        hi = int(min(nspat, np.ceil(center + half) + 1))
        if hi <= lo:
            centers[i] = center
            continue
        centers[i] = lo + float(np.argmax(profile[lo:hi]))

    left = np.empty(expected.size, dtype=float)
    right = np.empty(expected.size, dtype=float)
    for i, center in enumerate(centers):
        half = _search_half(i, centers, nspat)
        lo = int(max(0, np.floor(center - half)))
        hi = int(min(nspat, np.floor(center)))
        left[i] = lo + float(np.argmax(gradient[lo:hi])) if hi > lo else center
        lo = int(max(0, np.floor(center)))
        hi = int(min(nspat, np.ceil(center + half) + 1))
        right[i] = lo + float(np.argmin(gradient[lo:hi])) if hi > lo else center

    return left, right, centers

def trace_columns(
    gradient: np.ndarray,
    starts: np.ndarray,
    signs: np.ndarray,
    *,
    maxshift: float = 3.0,
    ref_row: int | None = None,
) -> np.ndarray:
    """Follow edge positions along the dispersion axis.

    Each edge is recentred row by row within ``maxshift`` pixels of its
    position in the adjacent row, starting from the reference row and working
    outward. ``signs`` selects rising (+1, left edges) or falling (-1, right
    edges) spatial gradients.

    Returns:
        An array of shape ``(nspec, len(starts))`` of tracked edge centroids.
    """
    gradient = np.asarray(gradient, dtype=float)
    nspec = gradient.shape[0]
    if ref_row is None:
        ref_row = nspec // 2
    cen = np.full((nspec, len(starts)), np.nan)
    for j, (start, sign) in enumerate(zip(np.atleast_1d(starts), np.atleast_1d(signs))):
        previous = _recenter(sign * gradient[ref_row], float(start), maxshift)
        cen[ref_row, j] = previous
        for row in range(ref_row + 1, nspec):
            previous = _recenter(sign * gradient[row], previous, maxshift)
            cen[row, j] = previous
        for row in range(ref_row - 1, -1, -1):
            previous = _recenter(sign * gradient[row], previous, maxshift)
            cen[row, j] = previous
    return cen

def fit_edge_traces(
    cen: np.ndarray,
    *,
    ncoeff: int,
    ref_row: int | None = None,
) -> tuple[list[np.ndarray], list[float]]:
    """Fit each tracked edge with a Legendre polynomial along dispersion.

    Args:
        cen: Edge centroid array of shape ``(nspec, n_edges)``.
        ncoeff: Number of polynomial coefficients (fit order ``ncoeff - 1``).
        ref_row: Central row used to normalize the dispersion coordinate.

    Returns:
        ``(coefficients, rms)`` lists, one entry per edge. A failed fit yields
        an all-NaN coefficient array and NaN RMS.
    """
    cen = np.asarray(cen, dtype=float)
    nspec = cen.shape[0]
    if ref_row is None:
        ref_row = (nspec - 1) // 2
    xmid, xscale = trace_coordinate(nspec)
    rows = np.arange(nspec)
    x = _xcoordinate(rows, xmid, xscale)

    coefficients: list[np.ndarray] = []
    rms: list[float] = []
    for edge in range(cen.shape[1]):
        values = cen[:, edge]
        valid = np.isfinite(values)
        if valid.sum() < ncoeff:
            coefficients.append(np.full(ncoeff, np.nan))
            rms.append(float("nan"))
            continue
        coeff = np.polynomial.legendre.legfit(x[valid], values[valid], ncoeff - 1)
        fitted = np.polynomial.legendre.legval(x[valid], coeff)
        coefficients.append(coeff)
        rms.append(float(np.sqrt(np.mean((values[valid] - fitted) ** 2))))
    return coefficients, rms
