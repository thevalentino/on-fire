subtract_sky

Model the two-dimensional sky background of each order, following the line tilt and avoiding the objects, and subtract it from the science image.

Inputs and outputs

Reads

  • science, science_ivar, science_var and science_mask from process_science.
  • order_traces from trace_orders.
  • tilt_coeffs from fit_tilts. The tilt surface sizes are read from the metadata that step recorded.
  • object_skymask, object_traces, object_orders and object_box_radii from find_objects.
  • No Frame Table role is loaded for this step.

Writes

| Product | Contents | |---------|----------| | sky_model | The fitted sky, same shape as the science image. | | science_sky | The science image minus the sky model. | | science_sky_var | Variance of science_sky: the science variance plus the scatter of the sky fit. | | science_sky_ivar | Inverse variance, 0 where the pixel is not usable. | | sky_fit_var | The extra variance contributed by the sky fit. |

Metadata recorded: sky_bspacing, sky_npoly, sky_local, n_orders_sky_subtracted and sky_residual_rms.

QA Artifact: sky_model, with the image, the sky model and the residual for each order.

An order with no usable trace, or too few sky pixels to fit, is skipped without being added to the Order Mask. Check n_orders_sky_subtracted in the metadata.

How to call it

Command line

onfire reduce config.yaml --until subtract_sky

Parameter Config

steps:
  subtract_sky:
    sky_bspacing: 30.0          # spacing of the B-spline breakpoints, in pixels (default max(15, nspec/12))
    sky_degree: 3               # B-spline degree, 3 is cubic (default 3)
    sky_npoly: 2                # Legendre degree across the order (default 2)
    sky_trim_edg: 3.0           # pixels to ignore inside each order edge (default 3.0)
    local_sky: true             # add a local correction around each object (default true)
    local_window_factor: 1.5    # width of that local window, in object box radii (default 1.5)

Numerical methods and idea

Telluric OH lines dominate the near-infrared sky, and they are tilted on the detector. A good model has to follow them along the line, not along the detector columns.

1. Tilted coordinate. For every pixel of an order, the dispersion row is corrected by the tilt model from fit_tilts. The result is the row the pixel would have if it sat on the order centre line:

$$ s = \text{row} - \delta(\text{row},\ \text{dspat}), $$

so a sky line has the same $s$ at every position across the slit. Without a tilt surface the plain row is used.

2. Fractional spatial coordinate. Each pixel also gets $u = (\text{col} - \text{left}) / (\text{right} - \text{left})$, between 0 at the left edge and 1 at the right.

3. Choose sky pixels. Pixels are used if they lie at least sky_trim_edg inside the order edges, are finite with positive inverse variance, and fall outside every object box (object_skymask).

4. Fit the surface. The sky is modelled as a product of a cubic B-spline in $s$, with breakpoints every sky_bspacing pixels, and a Legendre polynomial in $u$:

$$ \text{sky}(s, u) = \sum_{a,b} c_{ab}\, B_a(s)\, P_b(u). $$

The coefficients come from weighted least squares with weights $\sqrt{\text{ivar}}$ and iterative 3-sigma rejection, up to eight iterations. The surface is evaluated for the whole order, including under the objects. An order with fewer than max(30, degree + npoly + 4) sky pixels is skipped.

5. Local correction. If local_sky is on, a second, smaller fit is made to the residual in a window of local_window_factor times the object's box radius around each traced object, using finer breakpoints (half of sky_bspacing, but at least 5 pixels) and at most a linear term across the order. It is added to the sky model there.

6. Subtract and propagate. The sky model is subtracted from the science image. The residual variance of the sky fit, the squared RMS of its residuals, is added to the science variance.

def subtract_sky(
    products: dict[str, Any],
    meta: dict[str, Any],
    params: dict[str, Any],
) -> StepResult:
    """Model and subtract the 2D sky background per order (step 7).

    The sky is fit as a B-spline along the tilted spectral coordinate times a
    polynomial along the fractional spatial coordinate, using only background
    pixels (outside the object boxes). A local residual surface is then fit
    around each traced object. The resulting sky model is subtracted and the
    propagated variance is emitted alongside the sky-subtracted image.
    """
    image = products.get("science")
    if image is None:
        raise ValueError(
            "subtract_sky requires a 'science' product; run process_science first"
        )
    traces_product = products.get("order_traces")
    if traces_product is None:
        raise ValueError(
            "subtract_sky requires an 'order_traces' product; run trace_orders first"
        )
    image = np.asarray(image, dtype=float)
    nspec, nspat = image.shape
    ivar = products.get("science_ivar")
    ivar = (
        np.asarray(ivar, dtype=float)
        if ivar is not None
        else np.where(np.isfinite(image), 1.0, 0.0)
    )
    science_var = products.get("science_var")
    science_var = (
        np.asarray(science_var, dtype=float) if science_var is not None else 0.0 * image
    )
    science_mask = products.get("science_mask")
    skymask = products.get("object_skymask")
    if skymask is not None:
        skymask = np.asarray(skymask, dtype=bool)

    tilt_coeffs = products.get("tilt_coeffs")
    spec_order = int(meta.get("tilt_spec_order", 3))
    spat_order = int(meta.get("tilt_spat_order", 4))
    spat_scale = float(meta.get("tilt_spat_scale", 10.0))

    bspacing = float(params.get("sky_bspacing", max(15.0, nspec / 12.0)))
    degree = int(params.get("sky_degree", 3))
    npoly = int(params.get("sky_npoly", 2))
    trim_edg = float(params.get("sky_trim_edg", 3.0))
    do_local = bool(params.get("local_sky", True))
    local_factor = float(params.get("local_window_factor", 1.5))

    object_traces = products.get("object_traces")
    object_orders = products.get("object_orders")
    object_box_radii = products.get("object_box_radii")

    sky_global = np.zeros_like(image)
    sky_fit_var = np.zeros_like(image)
    sky_pixels = np.zeros_like(image, dtype=bool)
    n_sky_orders = 0

    qa_panels: list[tuple[int, np.ndarray, np.ndarray, np.ndarray]] = []

    cols = np.arange(nspat, dtype=float)[None, :]

    for index, order in enumerate(FIRE_ORDER_NUMBERS):
        order = int(order)
        edges = _order_edges(traces_product, order, nspec)
        if edges is None:
            continue
        left, right = edges
        fit = None
        if tilt_coeffs is not None and index < len(tilt_coeffs):
            coeffs = np.asarray(tilt_coeffs[index], dtype=float)
            if np.all(np.isfinite(coeffs)):
                fit = build_tilt_fit(
                    TiltFit(
                        coeffs=coeffs,
                        spec_order=spec_order,
                        spat_order=spat_order,
                        spec_scale=float(max(1, nspec - 1)),
                        spat_scale=spat_scale,
                        rms=float("nan"),
                        nlines=0,
                        tilt_angle=float("nan"),
                        masked=False,
                    )
                )
        spec_coord = tilted_coordinates(
            nspec, nspat, left, right, fit, spat_scale=spat_scale
        )
        width = right - left
        safe_width = np.where(width > 0, width, 1.0)
        on = (cols >= left[:, None] + trim_edg) & (cols <= right[:, None] - trim_edg)
        ximg = (cols - left[:, None]) / safe_width[:, None]
        good = on & np.isfinite(image) & (ivar > 0)
        if skymask is not None:
            good &= skymask
        if good.sum() < max(30, degree + npoly + 4):
            continue

        weights = np.sqrt(np.where(ivar > 0, ivar, 0.0))
        surface = fit_sky_surface(
            spec_coord[good],
            ximg[good],
            image[good],
            weights=weights[good],
            bspacing=bspacing,
            degree=degree,
            npoly=npoly,
        )
        sky_global[on] = surface.evaluate(spec_coord[on], ximg[on])
        if np.isfinite(surface.rms):
            # Added variance from the scatter of the sky-fit residuals.
            sky_fit_var[on] = surface.rms**2
        n_sky_orders += 1

        if (
            do_local
            and object_traces is not None
            and object_orders is not None
            and object_traces.shape[1] > 0
        ):
            members = np.where(np.asarray(object_orders, dtype=int) == order)[0]
            for j in members:
                positions = np.asarray(object_traces[:, j], dtype=float)
                if not np.any(np.isfinite(positions)):
                    continue
                radius = (
                    float(object_box_radii[j]) * local_factor
                    if object_box_radii is not None
                    else 8.0
                )
                near = np.abs(cols - positions[:, None]) <= radius
                window = near & on & np.isfinite(image) & (ivar > 0)
                if skymask is not None:
                    window &= skymask
                if window.sum() < 20:
                    continue
                residual = image - sky_global
                local_surface = fit_sky_surface(
                    spec_coord[window],
                    ximg[window],
                    residual[window],
                    weights=weights[window],
                    bspacing=max(bspacing / 2.0, 5.0),
                    degree=degree,
                    npoly=min(1, npoly),
                )
                target = near & on
                sky_global[target] += local_surface.evaluate(
                    spec_coord[target], ximg[target]
                )

        sky_pixels |= on & (skymask if skymask is not None else True)

        masked_image = np.where(on, image, np.nan)
        masked_model = np.where(on, sky_global, np.nan)
        masked_residual = np.where(on, image - sky_global, np.nan)
        qa_panels.append((order, masked_image, masked_model, masked_residual))

    science_sky = image - sky_global
    science_sky_var = science_var + sky_fit_var
    good_final = np.isfinite(science_sky)
    if science_mask is not None:
        good_final &= np.asarray(science_mask, dtype=bool)
    with np.errstate(invalid="ignore", divide="ignore"):
        sky_ivar = np.where(
            good_final,
            1.0 / np.maximum(science_sky_var, 1e-12),
            0.0,
        )

    qa = _sky_qa_figure(qa_panels)
    residual_scatter = (
        float(np.sqrt(np.mean(science_sky[sky_pixels] ** 2)))
        if sky_pixels.any()
        else float("nan")
    )
    return StepResult(
        products={
            "sky_model": sky_global,
            "sky_fit_var": sky_fit_var,
            "science_sky": science_sky,
            "science_sky_var": science_sky_var,
            "science_sky_ivar": sky_ivar,
        },
        meta={
            "sky_bspacing": bspacing,
            "sky_npoly": npoly,
            "sky_local": bool(do_local),
            "n_orders_sky_subtracted": int(n_sky_orders),
            "sky_residual_rms": residual_scatter,
        },
        plots={"sky_model": qa},
    )

def tilted_coordinates(
    nspec: int,
    nspat: int,
    left: np.ndarray,
    right: np.ndarray,
    fit,
    *,
    spat_scale: float,
) -> np.ndarray:
    """Build the tilted spectral coordinate across a full detector image.

    The coordinate follows the arc-line tilt: a pixel at spatial offset
    ``dspat`` from the order centre is assigned the spectral coordinate it
    would have on the order centre line. When no tilt surface is supplied the
    raw dispersion row coordinate is returned.

    Args:
        nspec: Number of dispersion pixels.
        nspat: Number of spatial pixels.
        left: Left order edge per dispersion row, in pixels.
        right: Right order edge per dispersion row, in pixels.
        fit: A :class:`~onfire.core.polyfit.PolynomialFit` tilt surface, or
            ``None`` to fall back to the row coordinate.
        spat_scale: Spatial normalization scale of the tilt surface.

    Returns:
        A ``(nspec, nspat)`` array of tilted spectral coordinates.
    """
    rows = np.arange(nspec, dtype=float)[:, None]
    row_grid = np.broadcast_to(rows, (nspec, nspat)).astype(float)
    if fit is None:
        return row_grid
    cols = np.arange(nspat, dtype=float)[None, :]
    center = 0.5 * (np.asarray(left, dtype=float) + np.asarray(right, dtype=float))[:, None]
    dspat = cols - center
    delta = evaluate_tilt_surface(
        fit,
        row_grid.ravel(),
        dspat.ravel(),
        nspec=nspec,
        spat_scale=spat_scale,
    ).reshape(nspec, nspat)
    return row_grid - delta

def fit_sky_surface(
    spec_coord: np.ndarray,
    ximg: np.ndarray,
    values: np.ndarray,
    *,
    weights: np.ndarray | None = None,
    bspacing: float = 30.0,
    degree: int = 3,
    npoly: int = 2,
    sigrej: float = 3.0,
    niter: int = 8,
) -> SkyFit:
    """Fit a 2D B-spline sky surface to the background pixels of one order.

    Args:
        spec_coord: Tilted spectral coordinate of each pixel.
        ximg: Fractional spatial coordinate (0 at the left edge, 1 at the right).
        values: Sky counts to fit.
        weights: Optional per-pixel fit weights, e.g. ``sqrt(ivar)``.
        bspacing: B-spline breakpoint spacing, in pixels.
        degree: B-spline degree (3 = cubic).
        npoly: Legendre polynomial degree along the spatial axis.
        sigrej: Rejection threshold in robust sigma.
        niter: Maximum number of rejection iterations.

    Returns:
        The fitted :class:`SkyFit`.
    """
    spec_coord = np.asarray(spec_coord, dtype=float).ravel()
    ximg = np.asarray(ximg, dtype=float).ravel()
    values = np.asarray(values, dtype=float).ravel()
    weights = None if weights is None else np.asarray(weights, dtype=float).ravel()

    finite = np.isfinite(spec_coord) & np.isfinite(ximg) & np.isfinite(values)
    if weights is not None:
        finite &= np.isfinite(weights) & (weights > 0)
    min_points = (degree + 1) + (npoly + 1) + 1
    domains = [(0.0, 1.0)]
    if finite.sum() < min_points:
        return SkyFit(
            basis=BSplineBasis.uniform(0.0, 1.0, bspacing, degree),
            npoly=npoly,
            poly_domains=domains,
            coeffs=np.zeros(1),
            rms=float("nan"),
            npoints=int(finite.sum()),
        )

    basis = BSplineBasis.uniform(
        spec_coord[finite].min(), spec_coord[finite].max(), bspacing, degree
    )
    xc = np.clip(ximg[finite], 0.0, 1.0)
    bspline = basis.design(spec_coord[finite])
    poly = design_matrix([xc], (npoly,), domains)
    design = (bspline[:, :, None] * poly[:, None, :]).reshape(finite.sum(), -1)
    fit_weights = weights[finite] if weights is not None else np.ones(finite.sum())
    coeffs, _, rms = robust_matrix_fit(
        design, values[finite], weights=fit_weights, niter=niter, sigrej=sigrej
    )
    return SkyFit(
        basis=basis,
        npoly=npoly,
        poly_domains=domains,
        coeffs=coeffs,
        rms=rms,
        npoints=int(finite.sum()),
    )
