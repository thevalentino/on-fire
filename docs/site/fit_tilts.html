fit_tilts

Measure how arc lines lean across the slit in every order and fit a smooth two-dimensional model of that tilt.

Inputs and outputs

Reads

  • arc_image, arc_spectra, order_centers and order_halfwidths, all produced by calibrate_wavelengths.
  • Frame Table role loaded for this step: arc.

Writes

| Product | Contents | |---------|----------| | tilts | Table with one row per order: nlines, rms, tilt_angle and masked. | | tilt_coeffs | Legendre coefficients of each order's tilt surface. | | tilt_surface_coeffs | Coefficients of one global surface pooled across all orders. | | tilt_measurements | Every measurement: order, spec_pixel, dspat, delta and the fitted model. |

An order is added to the Order Mask with the reason no arc spectrum, too few arc lines for tilts (fewer than three detected lines) or tilt tracing failed (fewer than four usable measurements).

QA Artifacts: tilt_residuals (fit residuals against dispersion pixel) and tilt_map (the tilt model for the first valid order).

How to call it

Command line

onfire reduce config.yaml --until fit_tilts

Parameter Config

steps:
  fit_tilts:
    spec_order: 3         # Legendre terms along the spectral axis (default 3)
    spat_order: 4         # Legendre terms along the spatial axis (default 4)
    tilt_sigdetect: 10.0  # line-detection threshold in noise sigma (default 10.0)
    fwhm: 4.0             # expected line FWHM in pixels (default 4.0)
    tilt_maxshift: 3.0    # largest line movement between neighbouring columns, in pixels (default 3.0)
    # spat_scale: 10.0    # spatial normalisation in pixels; default is the median order half-width minus 2

Python, one order, on a State Clone:

clone = baseline.run_step("fit_tilts", params={"tilt_sigdetect": 7.0}, clone=True, order=13)

A targeted run needs earlier tilt coefficients to refine. Without them order= has no effect and every order is fit.

Numerical methods and idea

In a curved echelle image a line of constant wavelength is not exactly along the spatial direction. It leans, and the lean varies with position. Sky subtraction and extraction later need to follow that lean, so this step measures it from arc lines and models it.

1. Pick lines. In each order the arc spectrum is searched for lines above tilt_sigdetect noise sigma, using the same line detector as calibrate_wavelengths.

2. Trace each line across the slit. Starting at the order centre, each line's spectral position is followed one spatial column at a time in both directions. At each column the new position is the centroid of the positive flux within tilt_maxshift pixels of the previous column's position. A line is dropped if it has fewer than three samples, or drifts by more than $3\,\mathrm{fwhm} + 1$ pixels.

Each sample is recorded as a pair: the spatial offset dspat from the order centre, and the spectral shift $\delta$ from the line's position at the centre.

3. Fit a surface. With the spectral pixel scaled by $n_\mathrm{spec} - 1$ and the spatial offset by spat_scale, the shift is fit with a two-dimensional Legendre surface:

$$ \frac{\delta}{n_\mathrm{spec}-1} \approx \sum_{j,k} c_{jk}\, P_j(s)\, P_k(u), \qquad s = \frac{\text{spec pixel}}{n_\mathrm{spec}-1}, \quad u = \frac{\text{dspat}}{\text{spat\_scale}}, $$

with spec_order terms in $j$ and spat_order terms in $k$, and 3-sigma robust rejection. The quoted tilt angle is the arctangent of the local slope $\partial\delta/\partial(\text{dspat})$ at the middle of the order.

4. Global surface. The measurements from all orders are also pooled into one global surface, stored as tilt_surface_coeffs.

Single-order re-runs (Cross-Order Regularization). With order= the target order is not fit freely. A low-order correction (one term per axis) to the global surface is fit to that order's residuals instead. A faint order with enough measurements then inherits the instrument-wide distortion. An order with fewer than four measurements is still masked with tilt tracing failed, as in a full run. After a single-order run, tilt_measurements holds only the target order's measurements.

def fit_tilts(
    products: dict[str, Any],
    meta: dict[str, Any],
    params: dict[str, Any],
) -> StepResult:
    """Model 2D spectral line tilts across each order (reduction step 4).

    Arc lines are traced across the spatial direction of every order and a 2D
    Legendre surface of the spectral-position offset is fit. A global surface
    pooled across all orders provides cross-order regularization when
    ``params['order']`` targets a single order.
    """
    arcimg = products.get("arc_image")
    spectra = products.get("arc_spectra")
    centers = products.get("order_centers")
    widths = products.get("order_halfwidths")
    if arcimg is None or spectra is None or centers is None:
        raise ValueError(
            "fit_tilts requires 'arc_image', 'arc_spectra' and 'order_centers' "
            "products; run calibrate_wavelengths first"
        )
    nspec = arcimg.shape[0]
    spec_order = int(params.get("spec_order", 3))
    spat_order = int(params.get("spat_order", 4))
    sigdetect = float(params.get("tilt_sigdetect", 10.0))
    fwhm = float(params.get("fwhm", 4.0))
    maxshift = float(params.get("tilt_maxshift", 3.0))
    nterms = spec_order * spat_order
    finite_widths = np.asarray(widths, dtype=float)[np.isfinite(widths)]
    spat_scale = float(
        params.get("spat_scale", np.median(finite_widths) - 2.0 if finite_widths.size else 10.0)
    )
    spat_scale = max(spat_scale, 1.0)

    previous_coeffs = products.get("tilt_coeffs")
    previous_table = products.get("tilts")
    target_index = _target_order_index(params)
    regen = target_index is not None and previous_coeffs is not None

    tilt_coeffs = np.full((FIRE_NORDERS, nterms), np.nan)
    table = _blank_tilt_table()
    if regen:
        tilt_coeffs[:] = np.asarray(previous_coeffs, dtype=float)
        if previous_table is not None:
            for name in TILT_COLUMNS:
                table[name] = previous_table[name]
        prior = _tilt_prior_from_coeffs(
            products.get("tilt_surface_coeffs"), spec_order, spat_order
        )
    else:
        prior = None

    indices = [target_index] if regen else list(range(FIRE_NORDERS))
    fits: list[TiltFit | None] = [None] * FIRE_NORDERS
    measurement_records: list[tuple[int, float, float, float, float]] = []
    pooled_spec: list[float] = []
    pooled_dspat: list[float] = []
    pooled_delta: list[float] = []
    masked_orders: dict[int, str] = {}

    for index in indices:
        order = int(FIRE_ORDER_NUMBERS[index])
        if (
            not np.all(np.isfinite(spectra[:, index]))
            or not np.any(np.isfinite(centers[:, index]))
        ):
            table["masked"][index] = True
            masked_orders[order] = "no arc spectrum"
            continue
        detected = detect_lines(spectra[:, index], sigdetect=sigdetect, fwhm=fwhm)
        if detected.tcent.size < 3:
            table["masked"][index] = True
            masked_orders[order] = "too few arc lines for tilts"
            continue
        center_spat = float(np.nanmedian(centers[:, index]))
        half_width = max(2.0, float(widths[index]) - 2.0)
        measurements = trace_tilts(
            arcimg,
            detected.tcent,
            center_spat,
            half_width=half_width,
            fwhm=fwhm,
            maxshift=maxshift,
        )
        if measurements.npoints < 4:
            table["masked"][index] = True
            masked_orders[order] = "tilt tracing failed"
            continue
        if regen:
            fit = regularize_tilt_fit(
                measurements,
                prior,
                nspec=nspec,
                spat_scale=spat_scale,
                spec_order=spec_order,
                spat_order=spat_order,
            )
        else:
            fit = fit_tilt_surface(
                measurements,
                nspec=nspec,
                spat_scale=spat_scale,
                spec_order=spec_order,
                spat_order=spat_order,
            )
            pooled_spec.extend(measurements.spec_pixel.tolist())
            pooled_dspat.extend(measurements.dspat.tolist())
            pooled_delta.extend(measurements.delta.tolist())
        poly = build_tilt_fit(fit)
        model = poly.evaluate(
            [measurements.spec_pixel / fit.spec_scale, measurements.dspat / fit.spat_scale]
        ) * fit.spec_scale
        measurement_records.extend(
            (order, float(s), float(d), float(dl), float(m))
            for s, d, dl, m in zip(
                measurements.spec_pixel,
                measurements.dspat,
                measurements.delta,
                model,
            )
        )
        fits[index] = fit
        tilt_coeffs[index] = fit.coeffs
        _write_tilt_row(table, index, fit)

    if regen:
        global_coeffs = products.get("tilt_surface_coeffs")
        if global_coeffs is None:
            global_coeffs = np.full(nterms, np.nan)
        global_coeffs = np.asarray(global_coeffs, dtype=float)
    else:
        global_fit = fit_global_tilt_surface(
            np.asarray(pooled_spec, dtype=float),
            np.asarray(pooled_dspat, dtype=float),
            np.asarray(pooled_delta, dtype=float),
            nspec=nspec,
            spat_scale=spat_scale,
            spec_order=spec_order,
            spat_order=spat_order,
        )
        global_coeffs = np.asarray(global_fit.coeffs, dtype=float)

    measurements_table = Table(
        {
            "order": np.asarray([r[0] for r in measurement_records], dtype=np.int16),
            "spec_pixel": np.asarray([r[1] for r in measurement_records], dtype=np.float64),
            "dspat": np.asarray([r[2] for r in measurement_records], dtype=np.float64),
            "delta": np.asarray([r[3] for r in measurement_records], dtype=np.float64),
            "model": np.asarray([r[4] for r in measurement_records], dtype=np.float64),
        },
        names=("order", "spec_pixel", "dspat", "delta", "model"),
    )

    residuals = _tilt_residual_figure(measurements_table, fits)
    tilt_map = _tilt_map_figure(arcimg, fits, spat_scale)

    n_masked = int(np.asarray(table["masked"], dtype=bool).sum())
    return StepResult(
        products={
            "tilts": table,
            "tilt_coeffs": tilt_coeffs,
            "tilt_surface_coeffs": global_coeffs,
            "tilt_measurements": measurements_table,
        },
        meta={
            "tilt_spec_order": spec_order,
            "tilt_spat_order": spat_order,
            "tilt_spat_scale": spat_scale,
            "n_orders_tilted": int(FIRE_NORDERS - n_masked),
            "n_orders_masked": n_masked,
        },
        plots={"tilt_residuals": residuals, "tilt_map": tilt_map},
        masked_orders=masked_orders,
    )

def trace_line_tilt(
    arcimg: np.ndarray,
    line_spec: float,
    center_spat: float,
    *,
    half_width: float,
    maxshift: float = 3.0,
) -> tuple[np.ndarray, np.ndarray]:
    """Trace one arc line's spectral position across the order.

    Args:
        arcimg: 2D arc image with shape ``(nspec, nspat)``.
        line_spec: Spectral pixel position of the line at the order centre.
        center_spat: Spatial pixel position of the order centre.
        half_width: Half-width of the spatial trace window, in pixels.
        maxshift: Maximum spectral shift between adjacent spatial samples.

    Returns:
        ``(dspat, positions)`` arrays of spatial offsets and the measured
        spectral positions.
    """
    arcimg = np.asarray(arcimg, dtype=float)
    nspat = arcimg.shape[1]
    center = int(round(center_spat))
    lo_spat = max(0, int(center_spat - half_width))
    hi_spat = min(nspat, int(center_spat + half_width) + 1)

    dspat: list[float] = []
    positions: list[float] = []
    guess = line_spec
    for column in range(center, hi_spat):
        guess = _centroid(arcimg[:, column], guess, maxshift)
        dspat.append(column - center_spat)
        positions.append(guess)
    guess = line_spec
    for column in range(center - 1, lo_spat - 1, -1):
        guess = _centroid(arcimg[:, column], guess, maxshift)
        dspat.append(column - center_spat)
        positions.append(guess)

    order = np.argsort(dspat)
    return np.asarray(dspat, dtype=float)[order], np.asarray(positions, dtype=float)[order]

def fit_tilt_surface(
    measurements: TiltMeasurements,
    *,
    nspec: int,
    spat_scale: float,
    spec_order: int = 3,
    spat_order: int = 4,
    sigrej: float = 3.0,
) -> TiltFit:
    """Fit the 2D spectral-offset surface for one order.

    Args:
        measurements: Traced tilt measurements.
        nspec: Number of detector pixels along dispersion.
        spat_scale: Spatial normalization scale (order half-width).
        spec_order: Polynomial order along the spectral axis.
        spat_order: Polynomial order along the spatial axis.
        sigrej: Rejection threshold in robust sigma.

    Returns:
        The fitted :class:`TiltFit`.
    """
    xnspecmin1 = float(max(1, nspec - 1))
    spat_scale = _spatial_scale(spat_scale)
    if measurements.npoints < 4:
        return _masked_tilt(nspec, spec_order, spat_order, spat_scale)

    spec_coord = measurements.spec_pixel / xnspecmin1
    spat_coord = measurements.dspat / spat_scale
    delta_norm = measurements.delta / xnspecmin1
    fit, good, _ = robust_legendre_fit(
        [spec_coord, spat_coord],
        delta_norm,
        (max(0, spec_order - 1), max(0, spat_order - 1)),
        domains=[(0.0, 1.0), (-1.0, 1.0)],
        sigrej=sigrej,
    )
    residual = (measurements.delta - xnspecmin1 * fit.evaluate([spec_coord, spat_coord]))[good]
    rms = float(np.sqrt(np.mean(residual**2))) if residual.size else float("nan")
    angle = tilt_angle(
        fit, nspec=nspec, spat_scale=spat_scale, spec_norm=0.5, spat_norm=0.0
    )
    return TiltFit(
        coeffs=np.asarray(fit.coeffs, dtype=float),
        spec_order=spec_order,
        spat_order=spat_order,
        spec_scale=xnspecmin1,
        spat_scale=spat_scale,
        rms=rms,
        nlines=int(np.unique(measurements.line_index).size),
        tilt_angle=angle,
        masked=False,
    )

def regularize_tilt_fit(
    measurements: TiltMeasurements,
    prior: PolynomialFit,
    *,
    nspec: int,
    spat_scale: float,
    spec_order: int = 3,
    spat_order: int = 4,
    correction_order: int = 1,
    sigrej: float = 3.0,
) -> TiltFit:
    """Refine one order's tilt surface using a global cross-order prior.

    A smooth low-order correction to the global surface is fit to the traced
    residuals, so a faint or noisy order inherits the instrument distortion
    rather than being dropped.

    Args:
        measurements: Traced tilt measurements for the target order.
        prior: Global tilt surface across all orders.
        nspec: Number of detector pixels along dispersion.
        spat_scale: Spatial normalization scale (order half-width).
        spec_order: Stored spectral polynomial order.
        spat_order: Stored spatial polynomial order.
        correction_order: Polynomial order of the correction surface.
        sigrej: Rejection threshold in robust sigma.

    Returns:
        The regularized :class:`TiltFit`.
    """
    xnspecmin1 = float(max(1, nspec - 1))
    spat_scale = _spatial_scale(spat_scale)
    if measurements.npoints < 4:
        return _tilt_from_prior(prior, nspec, spec_order, spat_order, spat_scale)

    spec_coord = measurements.spec_pixel / xnspecmin1
    spat_coord = measurements.dspat / spat_scale
    delta_norm = measurements.delta / xnspecmin1
    prior_delta = prior.evaluate([spec_coord, spat_coord])
    correction, _, _ = robust_legendre_fit(
        [spec_coord, spat_coord],
        delta_norm - prior_delta,
        (max(0, correction_order - 1), max(0, correction_order - 1)),
        domains=[(0.0, 1.0), (-1.0, 1.0)],
        sigrej=sigrej,
    )
    model = _combine_surface(prior, correction)
    residual = (
        measurements.delta
        - xnspecmin1 * model.evaluate([spec_coord, spat_coord])
    )
    rms = float(np.sqrt(np.mean(residual**2))) if residual.size else float("nan")
    angle = tilt_angle(
        model, nspec=nspec, spat_scale=spat_scale, spec_norm=0.5, spat_norm=0.0
    )
    return TiltFit(
        coeffs=np.asarray(model.coeffs, dtype=float),
        spec_order=spec_order,
        spat_order=spat_order,
        spec_scale=xnspecmin1,
        spat_scale=spat_scale,
        rms=rms,
        nlines=int(np.unique(measurements.line_index).size),
        tilt_angle=angle,
        masked=False,
    )
