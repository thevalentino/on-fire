Interactive analysis

The batch command is for getting a first reduction. When one order or one step looks wrong, work in Python. The loop is: clone, re-run, compare, commit.

Load a state

Every completed step leaves a checkpoint file. Load one back into a ReductionState, the container that holds the Intermediate State:

from onfire.pipeline.state import ReductionState

baseline = ReductionState.load("checkpoints/02_trace_orders.fits")
print(baseline.step, baseline.step_name)

Or add --interactive to onfire reduce to get an IPython session already bound to the final state.

Clone and re-run

A State Clone is an isolated copy. Change it freely; the Baseline is never touched.

clone = baseline.run_step(
    "trace_orders",
    params={"ncoeff": 7},
    clone=True,
    order=13,
)
  • params overrides the Parameter Config for this call only.
  • order=13 re-runs just that order. All other orders keep their previous results.
  • clone=True runs on a new State Clone and returns it. Without it, run_step changes the state you call it on.

A successful single-order re-run clears that order's Order Mask, since the old failure no longer applies.

onfire/pipeline/state.py:676
    def run_step(
        self,
        step: str | int,
        *,
        params: Optional[dict[str, Any]] = None,
        clone: bool = False,
        qa: bool = True,
        order: Optional[int] = None,
    ) -> "ReductionState":
        """Execute a reduction step, in place or on an isolated State Clone.

        Args:
            step: Step name or 1-based ordinal in the canonical sequence.
            params: Algorithmic parameter overrides merged over the config.
            clone: When ``True``, run on and return an independent State Clone,
                leaving this baseline state untouched.
            qa: When ``True``, attach any returned Plotly figures to :attr:`plots`.
            order: Target a single echelle order (interactive single-order runs).

        Returns:
            The mutated baseline state, or the new State Clone when ``clone`` is
            ``True``.
        """
        name = step if isinstance(step, str) else step_name(step)
        ordinal = step_ordinal(name)
        engine = get_step_engine(name)

        call_params = self.resolve_call_params(step, params=params, order=order)

        target = self.clone() if clone else self
        result = engine(target.products, target.meta, call_params)
        if not isinstance(result, StepResult):
            raise TypeError(
                f"engine for {name!r} returned {type(result).__name__}, "
                "expected StepResult"
            )

        target.products.update(result.products)
        target.meta.update(result.meta)
        if order is None:
            # A full run supersedes the step's earlier QA Artifacts; a
            # single-order run only replaces the artifacts it re-creates.
            target._drop_qa_artifacts({ordinal})
        if qa:
            target.plots.update(result.plots)
        if order is not None and int(order) not in result.masked_orders:
            # A successful targeted re-run is evidence the old mask no longer applies.
            target.order_mask.unmask(order)
        for masked_order, reason in result.masked_orders.items():
            target.order_mask.mask(masked_order, reason)
        # Keep the high-water mark: re-running an earlier step (e.g. a single
        # order) must not rewind the recorded progress.
        target.step = max(target.step, ordinal)
        target._record_run(ordinal, result, order, qa)
        target.lineage.revision += 1
        return target

Compare

compare builds one Plotly figure with this state on the left and the other on the right, from the QA Artifacts each recorded for that step:

fig = baseline.compare(clone, "trace_orders")
fig.show()

If either side has no QA Artifact for that step it raises ValueError, saying which orders are covered. A step can register its own comparison figure instead of the default pairing. telluric_correct does, to show the Empirical and Grid Telluric Correction side by side.

Stale products

Re-running an early step makes later products out of date: they were made with the old calibration. onfire does not delete them. It marks them Stale (per order, when you targeted one) so you can still look at them. They are discarded at Commit.

Commit

If the clone is better, adopt it:

baseline.commit(clone)

Commit replaces the Baseline wholesale and in place. Your existing variables stay valid, the clone is left unchanged, and any product still marked Stale is dropped. Recorded progress rewinds to the last step with no Stale products, so you re-run forward from there.

Nothing is written to disk by Commit. Save when you are ready:

baseline.save("checkpoints")

When Commit refuses

A clone made from a different state, or from a Baseline that has changed since the clone was made, is refused with ValueError. Pass force=True to commit anyway.

    def commit(self, clone: "ReductionState", *, force: bool = False) -> None:
        """Replace this Baseline wholesale with a State Clone.

        The Baseline object is mutated in place and the ``clone`` is left
        unchanged. Products still marked Stale on the clone are discarded and the
        recorded progress is rewound to the last step with no Stale products.
        Nothing is written to disk.

        Args:
            clone: A State Clone made from this state with :meth:`clone` or
                ``run_step(..., clone=True)``.
            force: Commit even if the clone is from an unrelated state or this
                Baseline has changed since the clone was made.

        Raises:
            ValueError: If the clone was not made from this state, or this
                Baseline has diverged since, and ``force`` is not set.
        """
        if not force:
            if clone.lineage.parent_uid != self.lineage.uid:
                raise ValueError(
                    "cannot commit: the clone was not made from this state "
                    "(unrelated lineage); pass force=True to commit anyway"
                )
            if clone.lineage.base_revision != self.lineage.revision:
                raise ValueError(
                    "cannot commit: this Baseline has diverged since the clone "
                    "was made; pass force=True to commit anyway"
                )
        snapshot = copy.deepcopy(clone)
        snapshot._discard_stale()
        self._adopt(snapshot)
        self.lineage.revision += 1
