The Parameter Config

The Parameter Config is a YAML file. Whatever you do not set takes a default, so the file only needs the things you want to change. It is kept separate from the Frame Table on purpose: the Frame Table says which data, the config says how to reduce it.

Pipeline defaults

| Key | Default | Meaning | |-----|---------|---------| | mode | pair_difference | How science frames are background-subtracted: pair_difference or stare. | | frames | frames.ascii | Frame Table path. | | output_dir | checkpoints | Where checkpoint files are written. | | qa_dir | qa | Where QA Artifact HTML files are written. | | steps | {} | Per-step parameter overrides (below). |

Step overrides

Parameters for one step live under steps:, keyed by the step name:

mode: pair_difference
steps:
  trace_orders:
    ncoeff: 6
    maxshift: 2.5

Which parameters each step accepts is listed on that step's page, under How to call it.

How a call is assembled

When a step runs, its parameters are layered, later layers winning:

  1. the top-level config keys (except steps, qa_dir, frames, output_dir),
  2. the step's own block under steps:,
  3. any parameters you pass explicitly in Python,
  4. the order you target, if any.

You can see what a step would be called with, without running it:

state.resolve_call_params("trace_orders")

    def resolve_call_params(
        self,
        step: str | int,
        *,
        params: Optional[dict[str, Any]] = None,
        order: Optional[int] = None,
    ) -> dict[str, Any]:
        """Return the effective parameters a step would be called with.

        The Parameter Config seeds the call (top-level control keys, then the
        step-specific ``steps.<name>`` block), explicit ``params`` override it,
        and a targeted ``order`` is added last. Pipeline-control keys
        (``steps``, ``qa_dir``, ``frames``, ``output_dir``) are not algorithm
        inputs and are never forwarded.
        """
        name = step if isinstance(step, str) else step_name(step)
        call_params: dict[str, Any] = {
            key: value
            for key, value in self.config.items()
            if key not in ("steps", "qa_dir", "frames", "output_dir")
        }
        call_params.update(self.config.get("steps", {}).get(name, {}) or {})
        call_params.update(params or {})
        if order is not None:
            call_params.setdefault("order", order)
        return call_params

def load_config(path: str | Path | None) -> dict[str, Any]:
    """Load a YAML Parameter Config merged onto :data:`DEFAULT_CONFIG`.

    Args:
        path: Path to a YAML file, or ``None`` to return the defaults.

    Returns:
        The resolved Parameter Config as a nested dictionary.

    Raises:
        FileNotFoundError: If ``path`` is provided but does not exist.
        TypeError: If the YAML document is not a mapping.
    """
    if path is None:
        return _merge(DEFAULT_CONFIG, {})
    text = Path(path).read_text()
    data = yaml.safe_load(text) or {}
    if not isinstance(data, dict):
        raise TypeError(f"Parameter Config must be a YAML mapping, got {type(data).__name__}")
    return _merge(DEFAULT_CONFIG, data)
