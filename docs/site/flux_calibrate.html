flux_calibrate

Use an observed standard star of known spectrum to derive a sensitivity function for each order, and apply it to turn extracted counts into flux density.

Inputs and outputs

Reads

  • wave_soln from calibrate_wavelengths.
  • objects from find_objects, and the extracted spectra from extract_1d: opt_flux and opt_var if present, otherwise boxcar_flux and boxcar_var.
  • standard_flux: the extracted standard-star spectrum, shape (nspec, 21) with one column per order, in counts. Optionally standard_var with the same shape.
  • Optionally standard_template, a table with wave and flux columns giving the standard's true spectrum. Without it the bundled A0V (Vega) template is used, or the file in a0v_path.
  • Frame Table role loaded for this step: standard.

Note: the standard_flux product is not produced by any earlier step. The runner loads the standard-star exposures as raw_standard, but nothing in the pipeline currently extracts them into standard_flux. Until that exists, put your own extracted standard spectrum into the state before running this step, for example state.products["standard_flux"] = counts. The tests do exactly this.

Writes

| Product | Contents | |---------|----------| | sensfunc | Table with one row per order: npoints, rms, wave_min, wave_max, coeff and masked. | | sensitivity | The conversion factor at every pixel, shape (nspec, 21). | | standard_fluxed | The standard star after calibration, for checking against standard_true. | | standard_true | The true spectrum of the standard on each order's wavelength grid. | | flux, flux_var, flux_ivar, flux_mask | The calibrated science spectra, with one column per object like the extract_1d matrices. |

An order is masked with the reason no standard star spectrum or sensitivity fit failed. Objects in a masked order get no calibrated flux.

QA Artifacts: sensitivity and flux_calibration.

How to call it

Command line

onfire reduce config.yaml --until flux_calibrate

Parameter Config

steps:
  flux_calibrate:
    standard_exptime: 60.0   # exposure time of the standard, seconds (default 1.0)
    science_exptime: 900.0   # exposure time of the science frames, seconds (default 1.0)
    sensfunc_order: 5        # degree of the sensitivity polynomial per order (default 5)
    sensfunc_niter: 8        # rejection iterations (default 8)
    sensfunc_sigrej: 3.0     # rejection threshold in robust sigma (default 3.0)
    # a0v_path: my_vega.fits # replace the bundled A0V template

The exposure times are not read from the Frame Table or the FITS headers. If you leave them at the default of 1.0 second, the calibrated fluxes are off by the ratio of the real times.

standard_airmass (default 1.0) is accepted, but the engine does not give derive_sensitivity an extinction curve, so it currently has no effect on the result.

Python, on a State Clone:

clone = baseline.run_step("flux_calibrate", params={"sensfunc_order": 4}, clone=True)
fig = baseline.compare(clone, "flux_calibrate")

This step always processes all orders. The engine does not read order=, so a targeted call would re-run every order anyway.

Numerical methods and idea

A standard star has a known spectrum. Dividing what the instrument recorded by what the star really emits gives the instrument's response, and that response then converts any other spectrum from counts to flux.

1. Counts to a rate per Angstrom. On each order's wavelength grid,

$$ N_\lambda = \frac{\text{counts}}{t_\mathrm{exp}\,\Delta\lambda}, $$

where $\Delta\lambda$ is the absolute gradient of the wavelength solution at each pixel.

2. Zeropoint. The true flux $F_\lambda$ of the standard (the template interpolated onto the order's wavelengths) gives a per-pixel AB-style zeropoint,

$$ Z = -2.5 \log_{10}\!\left(\frac{\lambda^2 F_\lambda}{N_\lambda}\right) + Z_0, $$

with $Z_0$ a unit-conversion constant fixed by the flux scale of $10^{-17}$ erg s$^{-1}$ cm$^{-2}$ Å$^{-1}$. Pixels with non-positive counts or ratios, non-finite values or no template coverage are left out.

3. Fit the sensitivity function. The zeropoints of each order are fit with a Legendre series of degree sensfunc_order against wavelength scaled to $[-1, 1]$, with iterative sensfunc_sigrej-sigma rejection for up to sensfunc_niter iterations.

4. Apply. For a science spectrum, the same rate $N_\lambda$ is formed with the science exposure time and multiplied by the conversion factor,

$$ F_\lambda = N_\lambda \,\frac{10^{-0.4\,(Z(\lambda) - Z_0)}}{\lambda^2}, $$

and the variance is scaled by the square of the whole linear factor, $\left(\text{factor} / (t_\mathrm{exp}\,\Delta\lambda)\right)^2$. A pixel is valid only where the factor is positive. The factor is zero where the fitted zeropoint falls outside 5 to 30.

To verify: the output flux unit. The engine docstring says erg s$^{-1}$ cm$^{-2}$ Å$^{-1}$, but the zeropoint constant is built with a $10^{-17}$ scale, so the numbers may carry that scale factor.

    A sensitivity function is derived for every order from an observed standard
    star of known intrinsic flux and then applied to the extracted science
    spectra, converting counts into flux density in erg/s/cm^2/Angstrom. The
    standard-star true flux comes from the ``standard_true`` product when

    Args:

        A :class:`StepResult` with the per-order ``sensfunc`` table, the sampled

            "run calibrate_wavelengths first"

            flux_ivar[:, j] = obj_ivar
        flux_mask[:, j] = obj_mask

            "standard_fluxed": standard_fluxed,

            "flux": flux,
            "flux_var": flux_var,
            "flux_ivar": flux_ivar,
            "flux_mask": flux_mask,
        },
        meta={
            "n_orders_flux_calibrated": int(FIRE_NORDERS - n_masked),
            "n_orders_masked": n_masked,
            "n_objects_flux_calibrated": n_objects,
            "sensfunc_order": sensfunc_order,

        masked_orders=masked_orders,

def counts_to_nlam(
    wave: np.ndarray,
    counts: np.ndarray,
    exptime: float,
    *,
    counts_ivar: np.ndarray | None = None,
    sampling: np.ndarray | None = None,
    extinction: object | None = None,
    airmass: float = 1.0,
) -> tuple[np.ndarray, np.ndarray | None]:
    """Convert counts to a count rate per Angstrom ``N_lam``.

    Args:
        wave: Wavelength grid in Angstroms, shape ``(nspec,)``.
        counts: Observed counts, shape ``(nspec,)``.
        exptime: Exposure time in seconds.
        counts_ivar: Optional inverse variance of ``counts``.
        sampling: Optional wavelength sampling ``dlambda``; defaults to the
            grid gradient.
        extinction: Optional atmospheric extinction coefficient array or a
            callable ``k(wave)`` returned in magnitudes per airmass.
        airmass: Airmass at which the observation was taken.

    Returns:
        ``(nlam, nlam_ivar)`` where ``nlam`` is in counts/s/Angstrom and
        ``nlam_ivar`` is ``None`` when ``counts_ivar`` was not supplied.
    """
    wave = np.asarray(wave, dtype=float)
    counts = np.asarray(counts, dtype=float)
    dw = delta_wave(wave) if sampling is None else np.asarray(sampling, dtype=float)
    exptime = float(exptime)

    with np.errstate(invalid="ignore", divide="ignore"):
        nlam = counts / exptime / dw
    nlam_ivar: np.ndarray | None = None
    if counts_ivar is not None:
        counts_ivar = np.asarray(counts_ivar, dtype=float)
        nlam_ivar = dw**2 * counts_ivar * exptime**2

    if extinction is not None:
        correction = _extinction_factor(extinction, wave, airmass)
        nlam = nlam * correction
        if nlam_ivar is not None:
            nlam_ivar = nlam_ivar / correction**2
    return nlam, nlam_ivar

def compute_zeropoint(
    wave: np.ndarray,
    nlam: np.ndarray,
    standard_flux: np.ndarray,
    *,
    gpm: np.ndarray | None = None,
    telluric: np.ndarray | None = None,
) -> tuple[np.ndarray, np.ndarray]:
    """Compute the spectroscopic zeropoint from a standard star.

    Args:
        wave: Wavelength grid in Angstroms.
        nlam: Observed count rate per Angstrom of the standard star.
        standard_flux: True flux of the standard star in erg/s/cm^2/Angstrom.
        gpm: Optional initial good-pixel mask.
        telluric: Optional atmospheric transmission to remove from the standard.

    Returns:
        ``(zeropoint, good)`` with the per-pixel zeropoint and its good mask.
    """
    wave = np.asarray(wave, dtype=float)
    nlam = np.asarray(nlam, dtype=float)
    standard_flux = np.asarray(standard_flux, dtype=float)
    transmission = (
        np.ones_like(wave) if telluric is None else np.asarray(telluric, dtype=float)
    )

    with np.errstate(invalid="ignore", divide="ignore"):
        ratio = np.square(wave) * transmission * standard_flux / nlam
        zeropoint = -2.5 * np.log10(np.where(ratio > 0, ratio, 1.0)) + ZP_UNIT_CONST

    good = (
        (wave > 1.0)
        & (nlam > 0)
        & (ratio > 0)
        & np.isfinite(standard_flux)
        & np.isfinite(zeropoint)
    )
    if gpm is not None:
        good &= np.asarray(gpm, dtype=bool)
    return zeropoint, good

def fit_sensitivity_function(
    wave: np.ndarray,
    zeropoint: np.ndarray,
    gpm: np.ndarray | None = None,
    *,
    order: int = 5,
    niter: int = 8,
    sigrej: float = 3.0,
) -> SensitivityFunction:
    """Fit a smooth sensitivity function to per-pixel zeropoints.

    Args:
        wave: Wavelength grid in Angstroms.
        zeropoint: Per-pixel spectroscopic zeropoint.
        gpm: Optional good-pixel mask.
        order: Legendre polynomial degree.
        niter: Maximum robust-rejection iterations.
        sigrej: Rejection threshold in robust sigma.

    Returns:
        The fitted :class:`SensitivityFunction`.
    """
    wave = np.asarray(wave, dtype=float)
    zeropoint = np.asarray(zeropoint, dtype=float)
    good = np.isfinite(wave) & np.isfinite(zeropoint)
    if gpm is not None:
        good &= np.asarray(gpm, dtype=bool)

    finite_wave = wave[good]
    if finite_wave.size:
        wave_min = float(finite_wave.min())
        wave_max = float(finite_wave.max())
    else:
        wave_min, wave_max = 0.0, 1.0

    fit, _used, rms = robust_legendre_fit(
        [wave],
        zeropoint,
        (int(order),),
        in_gpm=good,
        niter=int(niter),
        sigrej=float(sigrej),
    )
    return SensitivityFunction(
        wave_min=wave_min,
        wave_max=wave_max,
        coeffs=np.asarray(fit.coeffs, dtype=float),
        order=int(order),
        rms=float(rms),
    )

def apply_sensitivity(
    sensfunc: SensitivityFunction,
    wave: np.ndarray,
    counts: np.ndarray,
    *,
    exptime: float = 1.0,
    counts_var: np.ndarray | None = None,
    sampling: np.ndarray | None = None,
) -> tuple[np.ndarray, np.ndarray | None, np.ndarray | None, np.ndarray]:
    """Apply a sensitivity function to counts, returning flux density.

    Args:
        sensfunc: The per-order sensitivity function.
        wave: Wavelength grid in Angstroms.
        counts: Observed counts.
        exptime: Exposure time in seconds.
        counts_var: Optional variance of ``counts`` for propagation.
        sampling: Optional wavelength sampling ``dlambda``.

    Returns:
        ``(flux, flux_var, flux_ivar, mask)`` with flux in
        erg/s/cm^2/Angstrom and the variance propagated through the linear
        sensitivity and exposure-time scaling.
    """
    wave = np.asarray(wave, dtype=float)
    counts = np.asarray(counts, dtype=float)
    dw = delta_wave(wave) if sampling is None else np.asarray(sampling, dtype=float)
    exptime = float(exptime)
    nlam, _ = counts_to_nlam(
        wave, counts, exptime, sampling=dw
    )
    zeropoint = sensfunc.evaluate_zeropoint(wave)
    factor = nlam_to_flam(wave, zeropoint)
    flux = nlam * factor
    mask = np.isfinite(flux) & (factor > 0)

    if counts_var is None:
        return flux, None, None, mask

    # flux = counts * factor / (exptime * dlambda), so the variance transforms
    # by the square of that linear scaling.
    counts_var = np.asarray(counts_var, dtype=float)
    with np.errstate(invalid="ignore", divide="ignore"):
        flux_var = counts_var * (factor / (exptime * dw)) ** 2
        flux_ivar = np.where(flux_var > 0, 1.0 / flux_var, 0.0)
    flux = np.where(mask, flux, np.nan)
    flux_var = np.where(mask, flux_var, np.nan)
    flux_ivar = np.where(mask, flux_ivar, 0.0)
    return flux, flux_var, flux_ivar, mask
