calibrate_wavelengths

Find the emission lines in the arc spectrum of every order, identify them against the bundled FIRE archive, and fit a wavelength solution per order plus one global solution across orders.

Inputs and outputs

Reads

  • order_traces from trace_orders, to know where each order lies.
  • raw_arcs (or an existing arc_image): the arc exposures, averaged into one image.
  • Frame Table role loaded for this step: arc.
  • The bundled FIRE archive spectra and OH/arc line list, unless you point to your own files (see template_path and line_list_path below).

Writes

| Product | Contents | |---------|----------| | arc_image | The combined arc image. | | arc_spectra, order_centers, order_halfwidths | The extracted 1D arc spectrum per order, and where in the image it was taken. | | wavelengths | Table with one row per order, including its fit quality and masked flag. | | wave_soln | Wavelength at every dispersion pixel for every order, shape (nspec, 21). | | wave_coeffs | Legendre coefficients of each order's 1D solution. | | wave_surface, wave_surface_coeffs | The global 2D pixel-versus-order solution and its coefficients. | | line_ids | Table of every identified line: order, pixel, wave. |

An order is added to the Order Mask with the reason no arc spectrum (no usable trace or no archive template for it) or insufficient line identifications.

QA Artifacts: wavelength_residuals and wavelength_identifications.

How to call it

Command line

onfire reduce config.yaml --until calibrate_wavelengths

Parameter Config

steps:
  calibrate_wavelengths:
    ncoeff: 5            # coefficients of each order's stored 1D solution (default 5)
    arc_box_rad: 3.0     # half-width in pixels of the box used to extract the arc spectrum (default 3.0)
    sigdetect: 5.0       # line-detection threshold in noise sigma (default 5.0)
    fwhm: 4.0            # expected line FWHM in pixels (default 4.0)
    match_toler: 2.0     # matching tolerance in pixels of dispersion (default 2.0)
    n_first: 2           # polynomial order of the first-pass fit (default 2)
    n_final: 4           # polynomial order of the final fit (default 4)
    nspec_coeff: 4       # global surface: coefficients along the pixel axis (default 4)
    norder_coeff: 6      # global surface: coefficients along the order axis (default 6)

    # line_list_path: my_lines.dat     # optional replacement for the bundled line list

Numerical methods and idea

The idea is to avoid identifying lines from scratch. Each order has an archived arc spectrum with a known wavelength scale. The step aligns the observed spectrum to that archive, uses the alignment to guess each line's wavelength, and snaps the guess to the nearest true line in the line list.

1. Extract an arc spectrum per order. The arc image is summed over a box of $\pm$arc_box_rad pixels around the order centre, which is the midpoint of the fitted left and right edges from trace_orders, row by row.

2. Detect lines. The continuum is estimated with a running median filter, iteratively clipped so lines do not pull it up. After subtracting it, the noise is the robust scatter $1.4826 \times \mathrm{MAD}$. Local maxima above sigdetect times that noise, separated by at least one fwhm, are kept as lines. Each line centre is the flux-weighted centroid within $\pm 1.25\,$fwhm pixels.

3. Align to the archive. The observed and archived spectra are cross-correlated (using Fourier transforms) to find a pixel shift. The shift maps each detected line to an archive pixel, and the archive's wavelength scale turns that into a guessed wavelength.

4. Match to the line list. Each guess is matched to the nearest rest wavelength in the line list, accepted if closer than match_toler pixels' worth of wavelength. The tolerance is match_toler times the archive dispersion.

5. Fit and refine. The matched lines are fit with a Legendre polynomial of order n_first in pixel, with 3-sigma robust rejection. The fit is then used to predict where all detected lines should fall, new matches are added, and the fit is repeated with a higher order, up to n_final, for at most six iterations. An order with fewer than three detected lines, or fewer than three matches, is masked.

6. Global surface. All identified lines from all orders are fit together with a two-dimensional Legendre surface in pixel and order number, with nspec_coeff terms along pixel and norder_coeff along order (coordinates scaled to $[0,1]$). This needs at least nspec_coeff * norder_coeff matched lines; otherwise the stored surface is just a copy of the per-order solutions.

Single-order re-runs and Cross-Order Regularization. When order is given and a solution exists, the order is not solved from the archive again. Its detected lines are matched against the existing global surface as the prior (or the previous per-order solution if there is no surface). A smooth low-order correction to the prior is fit to the line residuals, so a faint order inherits the instrument-wide solution instead of failing. The matching tolerance is the larger of match_toler and 3.0. With fewer than three matches the prior is used unchanged. The global surface is not refit in a single-order run, so wave_surface stays as it was, and line_ids then lists only the target order's lines.

def calibrate_wavelengths(
    products: dict[str, Any],
    meta: dict[str, Any],
    params: dict[str, Any],
) -> StepResult:
    """Identify arc/OH lines and fit 1D dispersion solutions (reduction step 3).

    In a full run every order is reidentified against the bundled FIRE archive
    and a global 2D pixel-vs-order surface is fit across the orders. When
    ``params['order']`` targets a single order and a previous solution exists,
    that order is refined with cross-order regularization from the global
    surface while all other orders keep their fits.
    """
    from onfire.data import load_fire_line_list, load_fire_template

    arcimg = _combine_arcs(products)
    traces = products.get("order_traces")
    if traces is None:
        raise ValueError(
            "calibrate_wavelengths requires an 'order_traces' product; "
            "run trace_orders first"
        )
    nspec = arcimg.shape[0]
    ncoeff = int(params.get("ncoeff", 5))
    box_rad = float(params.get("arc_box_rad", 3.0))
    sigdetect = float(params.get("sigdetect", 5.0))
    fwhm = float(params.get("fwhm", 4.0))
    match_toler = float(params.get("match_toler", 2.0))
    n_first = int(params.get("n_first", 2))
    n_final = int(params.get("n_final", 4))
    nspec_coeff = int(params.get("nspec_coeff", 4))
    norder_coeff = int(params.get("norder_coeff", 6))

    template = load_fire_template(params.get("template_path"))
    line_list = load_fire_line_list(params.get("line_list_path"))
    line_waves = np.asarray(line_list["wave"], dtype=float)
    template_orders = np.asarray(template["order"], dtype=int)
    template_spectra = {
        int(order): (
            np.asarray(template["wave"][i], dtype=float),
            np.abs(np.asarray(template["flux"][i], dtype=float)),
        )
        for i, order in enumerate(template_orders)
    }

    spectra, centers, widths = _extract_order_spectra(arcimg, traces, box_rad)
    order_min = int(FIRE_ORDER_NUMBERS.min())
    order_max = int(FIRE_ORDER_NUMBERS.max())

    target_index = _target_order_index(params)
    previous_table = products.get("wavelengths")
    previous_soln = products.get("wave_soln")
    regen = target_index is not None and previous_soln is not None

    wave_soln = np.full((nspec, FIRE_NORDERS), np.nan)
    wave_coeffs = np.full((FIRE_NORDERS, ncoeff), np.nan)
    table = _blank_wavelength_table()
    records: list[tuple[int, float, float]] = []
    rows = np.arange(nspec, dtype=float)
    masked_orders: dict[int, str] = {}

    if regen:
        wave_soln[:] = np.asarray(previous_soln, dtype=float)
        if previous_table is not None:
            for name in WAVELENGTH_COLUMNS:
                table[name] = previous_table[name]
        if products.get("wave_coeffs") is not None:
            wave_coeffs[:] = np.asarray(products["wave_coeffs"], dtype=float)
        prior_surface = products.get("wave_surface")
        if prior_surface is not None:
            prior = np.asarray(prior_surface, dtype=float)[:, target_index]
        else:
            prior = wave_soln[:, target_index]
        solution = regularize_wavelength_solution(
            np.where(np.isfinite(spectra[:, target_index]), spectra[:, target_index], 0.0),
            line_waves,
            prior,
            sigdetect=sigdetect,
            fwhm=fwhm,
            match_toler=max(match_toler, 3.0),
            ncoeff=ncoeff,
        )
        wave_soln[:, target_index] = solution.wave_soln
        coeff, _, _ = fit_wavelength_solution(
            rows, solution.wave_soln, ncoeff=ncoeff, nspec=nspec
        )
        wave_coeffs[target_index] = coeff
        _write_wavelength_row(table, target_index, solution)
        records.extend(
            (int(FIRE_ORDER_NUMBERS[target_index]), float(p), float(w))
            for p, w in zip(solution.pixel_fit, solution.wave_fit)
        )
        wave_surface = prior_surface
        stored_coeffs = products.get("wave_surface_coeffs")
        if stored_coeffs is None:
            wave_surface_coeffs = np.full(nspec_coeff * norder_coeff, np.nan)
        else:
            wave_surface_coeffs = np.asarray(stored_coeffs, dtype=float)
    else:
        matched_pixel: list[float] = []
        matched_wave: list[float] = []
        matched_order: list[int] = []
        for index, order in enumerate(FIRE_ORDER_NUMBERS):
            order = int(order)
            if order not in template_spectra or not np.all(np.isfinite(spectra[:, index])):
                table["masked"][index] = True
                masked_orders[order] = "no arc spectrum"
                continue
            arxiv_wave, arxiv_flux = template_spectra[order]
            solution = reidentify_spectrum(
                spectra[:, index],
                arxiv_flux,
                arxiv_wave,
                line_waves,
                sigdetect=sigdetect,
                fwhm=fwhm,
                match_toler=match_toler,
                n_first=n_first,
                n_final=n_final,
            )
            if solution.masked:
                table["masked"][index] = True
                masked_orders[order] = "insufficient line identifications"
                continue
            wave_soln[:, index] = solution.wave_soln
            coeff, _, _ = fit_wavelength_solution(
                rows, solution.wave_soln, ncoeff=ncoeff, nspec=nspec
            )
            wave_coeffs[index] = coeff
            _write_wavelength_row(table, index, solution)
            records.extend(
                (order, float(p), float(w))
                for p, w in zip(solution.pixel_fit, solution.wave_fit)
            )
            matched_pixel.extend(solution.pixel_fit.tolist())
            matched_wave.extend(solution.wave_fit.tolist())
            matched_order.extend([order] * solution.pixel_fit.size)

        if len(matched_pixel) >= nspec_coeff * norder_coeff:
            fit, _ = fit_wavelength_surface(
                np.asarray(matched_pixel, dtype=float),
                np.asarray(matched_wave, dtype=float),
                np.asarray(matched_order, dtype=float),
                nspec=nspec,
                order_min=order_min,
                order_max=order_max,
                nspec_coeff=nspec_coeff,
                norder_coeff=norder_coeff,
            )
            wave_surface_coeffs = np.asarray(fit.coeffs, dtype=float)
            wave_surface = _evaluate_wavelength_surface(
                fit, nspec, order_min, order_max
            )
        else:
            wave_surface_coeffs = np.full(nspec_coeff * norder_coeff, np.nan)
            wave_surface = wave_soln.copy()

    line_ids = Table(
        {
            "order": np.asarray([r[0] for r in records], dtype=np.int16),
            "pixel": np.asarray([r[1] for r in records], dtype=np.float64),
            "wave": np.asarray([r[2] for r in records], dtype=np.float64),
        },
        names=("order", "pixel", "wave"),
    )
    if wave_surface is None:
        wave_surface = wave_soln.copy()

    residuals = _wavelength_residual_figure(table, wave_soln, line_ids)
    identifications = _wavelength_identification_figure(
        spectra, table, line_ids, wave_soln
    )

    n_masked = int(np.asarray(table["masked"], dtype=bool).sum())
    return StepResult(
        products={
            "arc_image": arcimg,
            "arc_spectra": spectra,
            "order_centers": centers,
            "order_halfwidths": widths,
            "wavelengths": table,
            "wave_soln": wave_soln,
            "wave_coeffs": wave_coeffs,
            "wave_surface": np.asarray(wave_surface, dtype=float),
            "wave_surface_coeffs": wave_surface_coeffs,
            "line_ids": line_ids,
        },
        meta={
            "n_orders_calibrated": int(FIRE_NORDERS - n_masked),
            "n_orders_masked": n_masked,
            "n_lines": int(line_ids["order"].size),
            "wave_surface_nspec_coeff": nspec_coeff,
            "wave_surface_norder_coeff": norder_coeff,
            "wave_order_min": order_min,
            "wave_order_max": order_max,
        },
        plots={
            "wavelength_residuals": residuals,
            "wavelength_identifications": identifications,
        },
        masked_orders=masked_orders,
    )

def detect_lines(
    spec: np.ndarray,
    *,
    sigdetect: float = 5.0,
    fwhm: float = 4.0,
    cont_frac_fwhm: float = 1.0,
    fit_frac_fwhm: float = 1.25,
    cont_samp: float = 30.0,
    niter_cont: int = 3,
) -> DetectedLines:
    """Detect emission lines in a 1D arc spectrum.

    Args:
        spec: The 1D arc spectrum.
        sigdetect: Detection threshold in units of the local noise.
        fwhm: Expected line FWHM in pixels, used for centroid windows and the
            minimum line separation.
        cont_frac_fwhm: Continuum sampling scale.
        fit_frac_fwhm: Centroid half-window, in units of ``fwhm``.
        cont_samp: Continuum sampling scale passed to :func:`iter_continuum`.
        niter_cont: Continuum rejection iterations.

    Returns:
        A :class:`DetectedLines` describing the detections.
    """
    spec = np.asarray(spec, dtype=float)
    cont = iter_continuum(
        spec, fwhm=fwhm, cont_samp=cont_samp * cont_frac_fwhm, niter_cont=niter_cont
    )
    cont_sub = spec - cont
    scatter = 1.4826 * np.median(np.abs(cont_sub - np.median(cont_sub)))
    if scatter <= 0:
        scatter = float(np.std(cont_sub)) or 1.0

    threshold = sigdetect * scatter
    candidates = _local_maxima(cont_sub)
    candidates = candidates[cont_sub[candidates] > threshold]
    peaks = _select_peaks(cont_sub, candidates, min_sep=max(1.0, fwhm))

    half = max(1, int(round(fit_frac_fwhm * fwhm)))
    nspec = cont_sub.size
    tcent = np.empty(peaks.size)
    tampl = np.empty(peaks.size)
    twid = np.empty(peaks.size)
    for i, peak in enumerate(peaks):
        lo = max(0, peak - half)
        hi = min(nspec, peak + half + 1)
        segment = np.clip(cont_sub[lo:hi], 0.0, None)
        total = segment.sum()
        columns = np.arange(lo, hi, dtype=float)
        if total > 0:
            centroid = float((columns * segment).sum() / total)
            width = float(np.sqrt((segment * (columns - centroid) ** 2).sum() / total))
        else:
            centroid = float(peak)
            width = float(fwhm)
        tcent[i] = centroid
        twid[i] = max(width, 1.0)
        tampl[i] = float(np.interp(centroid, np.arange(nspec), cont_sub))

    nsig = tampl / scatter
    good = nsig >= sigdetect
    return DetectedLines(
        tcent=tcent[good],
        tampl=tampl[good],
        twid=twid[good],
        nsig=nsig[good],
        cont_sub=cont_sub,
        good=good,
    )

def xcorr_shift(
    spec: np.ndarray,
    template: np.ndarray,
    *,
    max_lag_frac: float = 1.0,
    percent_ceil: float = 50.0,
) -> tuple[float, float]:
    """Cross-correlate an observed spectrum against a template.

    Args:
        spec: Observed arc spectrum.
        template: Template arc spectrum on the same pixel grid.
        max_lag_frac: Maximum lag to search, as a fraction of the spectrum
            length.
        percent_ceil: Upper percentile used to suppress the strongest lines
            before correlating.

    Returns:
        ``(shift, corr)`` where ``shift`` is the pixel shift such that
        ``template_pixel = observed_pixel - shift`` and ``corr`` is the
        normalized peak correlation.
    """
    spec = np.asarray(spec, dtype=float)
    template = np.asarray(template, dtype=float)
    n = spec.size
    if template.size != n:
        raise ValueError("spec and template must have the same length")
    a = _prep_xcorr(spec, percent_ceil)
    b = _prep_xcorr(template, percent_ceil)
    corr = np.fft.irfft(np.fft.rfft(a) * np.conj(np.fft.rfft(b)), n)
    lags = np.arange(n)
    lags = np.where(lags > n // 2, lags - n, lags)
    max_lag = int(max_lag_frac * n)
    allowed = np.abs(lags) <= max_lag
    masked = np.where(allowed, corr, -np.inf)
    best = int(np.argmax(masked))
    peak_lag = int(lags[best])
    denom = np.sqrt(np.sum(a**2) * np.sum(b**2))
    peak_corr = float(corr[best] / denom) if denom > 0 else 0.0
    return float(peak_lag), peak_corr

def reidentify_spectrum(
    spec: np.ndarray,
    arxiv_flux: np.ndarray,
    arxiv_wave: np.ndarray,
    line_waves: np.ndarray,
    *,
    sigdetect: float = 5.0,
    fwhm: float = 4.0,
    match_toler: float = 2.0,
    n_first: int = 2,
    n_final: int = 4,
    sigrej: float = 3.0,
    niter: int = 6,
) -> WavelengthSolution:
    """Determine a 1D wavelength solution by reidentifying the archive.

    The observed spectrum is cross-correlated with the bundled archive arc
    spectrum to obtain a pixel shift, each detected line is matched to the
    closest rest wavelength in the line list, and a Legendre solution is fit
    iteratively while new line matches are added.

    Args:
        spec: Extracted arc spectrum for one order.
        arxiv_flux: Archived composite arc spectrum (2040 pixels).
        arxiv_wave: Archived wavelength solution on the archive pixel grid.
        line_waves: Rest wavelengths of the OH line list.
        sigdetect: Line-detection threshold in noise sigma.
        fwhm: Expected line FWHM in pixels.
        match_toler: Wavelength-matching tolerance in pixels.
        n_first: Polynomial order of the first-pass fit.
        n_final: Polynomial order of the final fit.
        sigrej: Rejection threshold in robust sigma.
        niter: Maximum number of line-addition iterations.

    Returns:
        The fitted :class:`WavelengthSolution`.
    """
    spec = np.asarray(spec, dtype=float)
    nspec = spec.size
    line_waves = np.sort(np.asarray(line_waves, dtype=float))
    arxiv_flux_rs = _resample(arxiv_flux, nspec)
    arxiv_wave_rs = _resample(arxiv_wave, nspec)
    dispersion = abs(float(np.median(np.diff(arxiv_wave_rs))))
    tolerance = max(match_toler * dispersion, 1e-6)

    detected = detect_lines(spec, sigdetect=sigdetect, fwhm=fwhm)
    if detected.tcent.size < 3:
        return _masked_solution(nspec, ncoeff=n_first + 1)

    shift, _ = xcorr_shift(spec, arxiv_flux_rs)
    template_pixels = detected.tcent - shift
    wave_guess = np.interp(template_pixels, np.arange(nspec), arxiv_wave_rs)
    pixel_fit, wave_fit = _match_to_line_list(
        detected.tcent, wave_guess, line_waves, tolerance
    )

    if pixel_fit.size < 3:
        return _masked_solution(nspec, ncoeff=n_first + 1)

    solution = _solution_from_pixels(
        pixel_fit, wave_fit, nspec, ncoeff=n_first + 1, sigrej=sigrej
    )
    for _ in range(max(0, niter)):
        predicted = evaluate_wavelength_solution(
            solution.coeff, solution.xmid, solution.xscale, detected.tcent
        )
        extra_pixel, extra_wave = _match_to_line_list(
            detected.tcent, predicted, line_waves, tolerance
        )
        merged_pixel = np.concatenate([pixel_fit, extra_pixel])
        merged_wave = np.concatenate([wave_fit, extra_wave])
        unique, indices = np.unique(np.round(merged_pixel, 4), return_index=True)
        merged_pixel = unique
        merged_wave = merged_wave[indices]
        ncoeff = min(n_final + 1, max(n_first + 1, solution.coeff.size + 1))
        updated = _solution_from_pixels(
            merged_pixel, merged_wave, nspec, ncoeff=ncoeff, sigrej=sigrej
        )
        if updated.nlines <= solution.nlines and ncoeff == solution.coeff.size:
            solution = updated
            break
        solution = updated
    return solution

def regularize_wavelength_solution(
    spec: np.ndarray,
    line_waves: np.ndarray,
    prior_wave: np.ndarray,
    *,
    sigdetect: float = 5.0,
    fwhm: float = 4.0,
    match_toler: float = 3.0,
    ncoeff: int = 5,
    correction_order: int = 1,
    sigrej: float = 3.0,
) -> WavelengthSolution:
    """Refine one order using cross-order regularization from a global prior.

    The global solution ``prior_wave`` provides predicted wavelengths at every
    pixel. Newly detected lines are matched to the line list and a smooth,
    low-order correction to the global solution is fit. Orders with too few
    matches fall back to the global prior, so faint orders inherit the
    instrument solution instead of failing.

    Args:
        spec: Extracted arc spectrum for the target order.
        line_waves: Rest wavelengths of the OH line list.
        prior_wave: Global wavelength solution evaluated at every pixel, shape
            ``(nspec,)``.
        sigdetect: Line-detection threshold in noise sigma.
        fwhm: Expected line FWHM in pixels.
        match_toler: Matching tolerance in pixels.
        ncoeff: Number of coefficients of the stored 1D solution.
        correction_order: Polynomial order of the smooth correction.
        sigrej: Rejection threshold in robust sigma.

    Returns:
        The regularized :class:`WavelengthSolution`.
    """
    spec = np.asarray(spec, dtype=float)
    prior_wave = np.asarray(prior_wave, dtype=float)
    nspec = spec.size
    rows = np.arange(nspec, dtype=float)
    line_waves = np.sort(np.asarray(line_waves, dtype=float))
    dispersion = abs(float(np.median(np.diff(prior_wave))))
    tolerance = max(match_toler * dispersion, 1e-6)

    detected = detect_lines(spec, sigdetect=sigdetect, fwhm=fwhm)
    guess = np.interp(detected.tcent, rows, prior_wave)
    pixel_fit, wave_fit = _match_to_line_list(
        detected.tcent, guess, line_waves, tolerance
    )

    if pixel_fit.size < 3:
        return _fallback_solution(prior_wave, ncoeff=ncoeff)

    prior_at_lines = np.interp(pixel_fit, rows, prior_wave)
    residual = wave_fit - prior_at_lines
    fit, _, _ = robust_legendre_fit(
        [pixel_fit],
        residual,
        (max(0, correction_order),),
        domains=[(0.0, float(max(1, nspec - 1)))],
        sigrej=sigrej,
    )
    correction = fit.evaluate([rows])
    wave_soln = prior_wave + correction

    coeff, _, rms = fit_wavelength_solution(
        rows, wave_soln, ncoeff=ncoeff, nspec=nspec, sigrej=sigrej
    )
    xmid, xscale = trace_xcoord(nspec)
    return WavelengthSolution(
        coeff=coeff,
        xmid=xmid,
        xscale=xscale,
        rms=rms,
        nlines=int(pixel_fit.size),
        pixel_fit=pixel_fit,
        wave_fit=wave_fit,
        wave_soln=wave_soln,
        cen_wave=float(wave_soln[nspec // 2]),
        cen_disp=float(wave_soln[min(nspec - 1, nspec // 2 + 1)] - wave_soln[nspec // 2]),
        masked=False,
    )

    order: np.ndarray,
    *,
    nspec: int,
    order_min: int,
    order_max: int,
    nspec_coeff: int = 4,
    norder_coeff: int = 6,
    sigrej: float = 3.0,
) -> tuple[PolynomialFit, float]:
    """Fit the global 2D pixel-vs-order wavelength surface.

    Args:
        pixel: Detector pixel positions of all identified lines.
        wave: Assigned wavelengths.
        order: Echelle order number of each line.
        nspec: Number of detector pixels along dispersion.
        order_min: Minimum echelle order number.
        order_max: Maximum echelle order number.
        nspec_coeff: Polynomial order along the pixel axis.
        norder_coeff: Polynomial order along the order axis.
        sigrej: Rejection threshold in robust sigma.

    Returns:
        ``(fit, rms)`` with the fitted surface (normalized pixel and order
        coordinates in ``[0, 1]``) and its RMS residual in Angstrom.
    """
    pixel = np.asarray(pixel, dtype=float)
    wave = np.asarray(wave, dtype=float)
    order = np.asarray(order, dtype=float)
    span = float(max(1, order_max - order_min))
    spec_coord = pixel / float(max(1, nspec - 1))
    order_coord = (order - order_min) / span
    fit, _, _ = robust_legendre_fit(
        [spec_coord, order_coord],
        wave,
        (max(0, nspec_coeff - 1), max(0, norder_coeff - 1)),
        domains=[(0.0, 1.0), (0.0, 1.0)],
        sigrej=sigrej,
    )
    residual = wave - fit.evaluate([spec_coord, order_coord])
    rms = float(np.sqrt(np.mean(residual**2))) if residual.size else float("nan")
    return fit, rms
