extract_1d

Turn the sky-subtracted image into one-dimensional spectra, one per object and order, with both a simple boxcar sum and an optimal (profile-weighted) extraction.

Inputs and outputs

Reads

  • science_sky and science_sky_ivar from subtract_sky, and science_mask from process_science.
  • objects and object_traces from find_objects.
  • order_traces from trace_orders.
  • No Frame Table role is loaded for this step.

Writes

The spectra are matrices with one column per object in objects, in the same order, and nspec rows.

| Product | Contents | |---------|----------| | extractions | Table with one row per object: the profile fit and per-object summaries. | | boxcar_flux, boxcar_var, boxcar_ivar, boxcar_npix, boxcar_mask | The boxcar spectrum, its variance and inverse variance, pixels summed, and validity. | | opt_flux, opt_var, opt_ivar, opt_chi2, opt_frac_use, opt_mask | The optimal spectrum, its variance and inverse variance, a per-row reduced chi-squared, the profile fraction used, and validity. | | extraction_cr_mask | Image of pixels rejected as cosmic rays. |

Metadata recorded: n_objects_extracted, n_orders_extracted, n_cosmic_rays and the profile and rejection settings used.

An object that is masked in objects, or has no finite trace, gets an empty column. An object in an order with no usable trace also adds no order trace to the Order Mask.

QA Artifacts: extraction_spectra, extraction_noise and extraction_profiles.

How to call it

    # box_radius: 6.0          # boxcar half-width in pixels; default is each object's own box radius

Numerical methods and idea

Two extractions are made for every object because they trade simplicity against signal-to-noise.

Boxcar. For each dispersion row the usable pixels within box_radius of the object trace are summed, and their variances are added. No assumption about the object's shape is needed, but pixels with no flux still add noise.

Optimal extraction (Horne 1986). The object's spatial profile is measured once and then used to weight each row.

  1. Collapse the profile. Every row contributes the pixels within profile_half_width of the trace, weighted by inverse variance, and these are averaged by integer offset from the trace.
  2. Fit it. A Gaussian is fit by a least-squares parabola to the logarithm of the profile (using samples above 5% of the peak), or, with profile_model: polynomial, a Legendre series of profile_order terms.
  3. Normalise per row. The fitted profile is placed on the trace and divided by its sum over the unmasked pixels, so each row of $P$ sums to one.
  4. Weight. With data $D$, inverse variance $w$ and profile $P$ in a row,

$$ f = \frac{\sum_x w\,P\,D}{\sum_x w\,P^2}, \qquad w_f = \frac{\sum_x w\,P^2}{\sum_x P}, $$

where $f$ is the extracted flux and $w_f$ is its inverse variance.

Cosmic rays. After each pass the model $f\,P$ is subtracted. A pixel is rejected if its positive residual exceeds cr_sigclip times the larger of its formal noise and the robust scatter of all residuals. The extraction is repeated, up to cr_niter times, until nothing new is rejected.

Validity. A row of the optimal spectrum is kept only if more than min_frac_use of the profile survived the masking.

def extract_1d(
    products: dict[str, Any],
    meta: dict[str, Any],
    params: dict[str, Any],
) -> StepResult:
    """Perform boxcar and optimal 1D extraction per order (reduction step 8).

    Every object traced by :func:`find_objects` is extracted from the
    sky-subtracted image with both a boxcar sum and Horne optimal extraction.
    The optimal extraction fits a spatial profile to each object and rejects
    cosmic rays, propagating formal variance and bad-pixel flags throughout.
    When ``params['order']`` targets a single order and a previous
    ``extractions`` product exists, only that order is re-extracted while all
    other orders keep their results.

    Args:
        products: State products; must contain ``science_sky``, ``objects`` and
            ``order_traces``.
        meta: State metadata (unused).
        params: Algorithmic parameters, including optional ``order`` targeting.

    Returns:
        A :class:`StepResult` with a structured ``extractions`` table, 2D flux,
        variance, inverse-variance, mask, and cosmic-ray products, and QA
        figures for spectra, noise, and spatial profiles.
    """
    image = products.get("science_sky")
    if image is None:
        raise ValueError(
            "extract_1d requires a 'science_sky' product; run subtract_sky first"
        )
    objects = products.get("objects")
    if objects is None:
        raise ValueError(
            "extract_1d requires an 'objects' product; run find_objects first"
        )
    traces_product = products.get("order_traces")
    if traces_product is None:
        raise ValueError(
            "extract_1d requires an 'order_traces' product; run trace_orders first"
        )
    image = np.asarray(image, dtype=float)
    nspec, nspat = image.shape
    ivar = products.get("science_sky_ivar")
    ivar = (
        np.asarray(ivar, dtype=float)
        if ivar is not None
        else np.where(np.isfinite(image), 1.0, 0.0)
    )
    base_mask = np.isfinite(image) & np.isfinite(ivar) & (ivar > 0)
    science_mask = products.get("science_mask")
    if science_mask is not None:
        base_mask &= np.asarray(science_mask, dtype=bool)

    object_traces = products.get("object_traces")
    positions = (
        np.asarray(object_traces, dtype=float)
        if object_traces is not None and np.asarray(object_traces).ndim == 2
        else _positions_from_table(objects, nspec)
    )
    if positions.shape[1] != len(objects):
        positions = _positions_from_table(objects, nspec)

    orders = np.asarray(objects["order"], dtype=int)
    obj_ids = np.asarray(objects["obj_id"], dtype=int)
    object_box_radii = products.get("object_box_radii")
    object_box_radii = (
        np.asarray(object_box_radii, dtype=float)
        if object_box_radii is not None
        else np.asarray(objects["box_radius"], dtype=float)
    )

    box_radius_param = params.get("box_radius")
    profile_model = str(params.get("profile_model", "gaussian"))
    profile_order = int(params.get("profile_order", 2))
    min_frac_use = float(params.get("min_frac_use", 0.5))
    cr_sigclip_param = params.get("cr_sigclip", 5.0)
    cr_sigclip = None if cr_sigclip_param is None else float(cr_sigclip_param)
    cr_niter = int(params.get("cr_niter", 3))
    profile_half_width_param = params.get("profile_half_width")

    target_index = _target_order_index(params)
    existing = products.get("extractions")
    reuse = (
        target_index is not None
        and existing is not None
        and len(existing) == len(objects)
    )
    target_order = int(FIRE_ORDER_NUMBERS[target_index]) if reuse else None

    records: list[dict[str, Any]] = []
    profiles: list[tuple[str, np.ndarray, np.ndarray, Any]] = []
    cr_images: list[np.ndarray] = []
    masked_orders: dict[int, str] = {}
    columns = np.arange(nspat, dtype=float)[None, :]

    for j in range(len(objects)):
        order = int(orders[j])
        obj_id = int(obj_ids[j])
        box_radius = (
            float(box_radius_param)
            if box_radius_param is not None
            else float(object_box_radii[j])
        )

            records.append(_record_from_table_row(existing, j, nspec))
            continue
        if bool(objects["masked"][j]) or not np.any(np.isfinite(positions[:, j])):
            records.append(_blank_record(order, obj_id, nspec, box_radius))
            continue
        edges = _order_edges(traces_product, order, nspec)
        if edges is None:
            records.append(_blank_record(order, obj_id, nspec, box_radius))
            masked_orders.setdefault(order, "no order trace")
            continue

        half_width = (
            float(profile_half_width_param)
            if profile_half_width_param is not None
            else max(3.0, abs(box_radius))
        )
        box, optimal, fit, offsets, template, _profile_image = _extract_object(
            image,
            ivar,
            on_order,
            positions[:, j],
            box_radius=box_radius,
            profile_half_width=half_width,

            profile_order=profile_order,
            min_frac_use=min_frac_use,
            cr_sigclip=cr_sigclip,
            cr_niter=cr_niter,
        )
        records.append(

        )

    def _matrix(key: str, fill: float) -> np.ndarray:
        matrix = np.full((nspec, len(records)), fill, dtype=float)
        for j, record in enumerate(records):
            values = np.asarray(record[key], dtype=float)
            if values.size == nspec:
                matrix[:, j] = values
        return matrix

    combined_cr = np.zeros((nspec, nspat), dtype=bool)
    for cr in cr_images:
        if cr.shape == combined_cr.shape:
            combined_cr |= cr

    boxcar_mask = np.zeros((nspec, len(records)), dtype=bool)
    opt_mask = np.zeros((nspec, len(records)), dtype=bool)
    for j, record in enumerate(records):
        boxcar_mask[:, j] = np.isfinite(record["boxcar_flux"])
        opt_mask[:, j] = np.isfinite(record["opt_flux"])

    n_extracted = int(np.any(opt_mask, axis=0).sum()) if records else 0
    extracted_orders = {
        int(records[j]["order"]) for j in range(len(records)) if np.any(opt_mask[:, j])
    }

    spectra_figure = _extraction_spectra_figure(records)
    noise_figure = _extraction_noise_figure(records)
    profile_figure = _extraction_profile_figure(profiles)

    return StepResult(
        products={
            "extractions": table,
            "boxcar_flux": _matrix("boxcar_flux", np.nan),
            "boxcar_var": _matrix("boxcar_var", np.nan),
            "boxcar_ivar": _matrix("boxcar_ivar", 0.0),
            "boxcar_npix": _matrix("boxcar_npix", 0.0),
            "boxcar_mask": boxcar_mask,
            "opt_flux": _matrix("opt_flux", np.nan),
            "opt_var": _matrix("opt_var", np.nan),
            "opt_ivar": _matrix("opt_ivar", 0.0),
            "opt_chi2": _matrix("opt_chi2", np.nan),
            "opt_frac_use": _matrix("opt_frac_use", 0.0),
            "opt_mask": opt_mask,
            "extraction_cr_mask": combined_cr,
        },
        meta={
            "n_objects_extracted": n_extracted,
            "n_orders_extracted": len(extracted_orders),
            "n_cosmic_rays": int(combined_cr.sum()),
            "extraction_profile_model": profile_model,
            "extraction_profile_order": profile_order,
            "extraction_min_frac_use": min_frac_use,
            "extraction_cr_sigclip": cr_sigclip,

        plots={
            "extraction_spectra": spectra_figure,
            "extraction_noise": noise_figure,
            "extraction_profiles": profile_figure,
        },
        masked_orders=masked_orders,

def _extract_object(
    image: np.ndarray,
    ivar: np.ndarray,
    mask: np.ndarray,
    trace: np.ndarray,
    *,
    box_radius: float,
    profile_half_width: float,
    profile_model: str,
    profile_order: int,
    min_frac_use: float,
    cr_sigclip: float | None,
    cr_niter: int,
) -> tuple[Any, Any, Any, np.ndarray, np.ndarray, np.ndarray]:
    """Extract one object with boxcar and optimal methods, returning diagnostics."""
    box = boxcar_extract(image, ivar, trace, box_radius, mask=mask)
    offsets, template = collapse_object_profile(
        image, ivar, trace, half_width=profile_half_width, mask=mask
    )
    fit = fit_object_profile(
        offsets, template, model=profile_model, order=profile_order
    )
    profile_image = build_profile_image(
        fit, trace, image.shape, half_width=profile_half_width, mask=mask
    )
    optimal = optimal_extract(
        image,
        ivar,
        profile_image,
        mask=mask,
        min_frac_use=min_frac_use,
        sigclip=cr_sigclip,
        niter=cr_niter,
    )
    return box, optimal, fit, offsets, template, profile_image

def boxcar_extract(
    image: np.ndarray,
    ivar: np.ndarray,
    trace: np.ndarray,
    box_radius: float,
    *,
    mask: np.ndarray | None = None,
) -> BoxcarExtraction:
    """Sum the flux in a box around the object trace.

    Args:
        image: Sky-subtracted order image, shape ``(nspec, nspat)``.
        ivar: Inverse-variance image, same shape as ``image``.
        trace: Object spatial trace, shape ``(nspec,)``.
        box_radius: Half-width of the extraction box, in pixels.
        mask: Optional good-pixel mask, same shape as ``image``.

    Returns:
        The :class:`BoxcarExtraction`, including the propagated variance.
    """
    image = np.asarray(image, dtype=float)
    ivar = np.asarray(ivar, dtype=float)
    trace = np.asarray(trace, dtype=float)
    nspec, nspat = image.shape
    radius = float(box_radius)

    flux = np.full(nspec, np.nan)
    variance = np.full(nspec, np.nan)
    npix = np.zeros(nspec, dtype=float)
    good_spectrum = np.zeros(nspec, dtype=bool)

    for row in range(nspec):
        centre = trace[row]
        if not np.isfinite(centre):
            continue
        low = int(np.ceil(centre - radius))
        high = int(np.floor(centre + radius))
        if high < low:
            continue
        columns = np.arange(low, high + 1)
        inside = (columns >= 0) & (columns < nspat)
        if not inside.any():
            continue
        columns = columns[inside]
        good = np.isfinite(image[row, columns]) & (ivar[row, columns] > 0)
        if mask is not None:
            good &= np.asarray(mask, dtype=bool)[row, columns]
        if not good.any():
            continue
        flux[row] = float(image[row, columns][good].sum())
        variance[row] = float((1.0 / ivar[row, columns][good]).sum())
        npix[row] = float(good.sum())
        good_spectrum[row] = True

    with np.errstate(invalid="ignore", divide="ignore"):
        ivar_out = np.where(good_spectrum, 1.0 / variance, 0.0)
    return BoxcarExtraction(
        flux=flux,
        var=variance,
        ivar=ivar_out,
        npix=npix,
        mask=good_spectrum,
    )

def collapse_object_profile(
    image: np.ndarray,
    ivar: np.ndarray,
    trace: np.ndarray,
    *,
    half_width: float,
    mask: np.ndarray | None = None,
) -> tuple[np.ndarray, np.ndarray]:
    """Collapse an order image into an inverse-variance weighted object profile.

    Each dispersion row contributes the pixels within ``half_width`` of its
    object trace, weighted by that pixel's inverse variance, producing a mean
    spatial profile as a function of integer pixel offset from the trace.

    Args:
        image: Sky-subtracted order image, shape ``(nspec, nspat)``.
        ivar: Inverse-variance image, same shape as ``image``.
        trace: Object spatial trace, shape ``(nspec,)``.
        half_width: Half-width of the collapse window, in pixels.
        mask: Optional good-pixel mask, same shape as ``image``.

    Returns:
        ``(offsets, profile)`` with the integer pixel offsets and the collapsed
        profile values (NaN where no pixel contributed).
    """
    image = np.asarray(image, dtype=float)
    ivar = np.asarray(ivar, dtype=float)
    trace = np.asarray(trace, dtype=float)
    nspec, nspat = image.shape
    half_width = int(max(1, round(float(half_width))))
    offsets = np.arange(-half_width, half_width + 1, dtype=int)
    good = np.isfinite(image) & (ivar > 0)
    if mask is not None:
        good &= np.asarray(mask, dtype=bool)

    numerator = np.zeros(offsets.size, dtype=float)
    denominator = np.zeros(offsets.size, dtype=float)
    for row in range(nspec):
        centre = trace[row]
        if not np.isfinite(centre):
            continue
        columns = int(round(centre)) + offsets
        inside = (columns >= 0) & (columns < nspat)
        if not inside.any():
            continue
        columns = columns[inside]
        row_good = good[row, columns]
        weights = np.where(row_good, ivar[row, columns], 0.0)
        numerator[inside] += weights * np.where(row_good, image[row, columns], 0.0)
        denominator[inside] += weights

    with np.errstate(invalid="ignore", divide="ignore"):
        profile = numerator / denominator
    profile = np.where(denominator > 0, profile, np.nan)
    return offsets, profile

def optimal_extract(
    image: np.ndarray,
    ivar: np.ndarray,
    profile: np.ndarray,
    *,
    mask: np.ndarray | None = None,
    min_frac_use: float = 0.5,
    sigclip: float | None = 5.0,
    niter: int = 3,
) -> OptimalExtraction:
    """Perform Horne (1986) optimal extraction of a single object.

    The flux estimate is ``sum(ivar * P * D) / sum(ivar * P**2)`` and its
    inverse variance is ``sum(ivar * P**2) / sum(P)``, where ``P`` is the
    per-row normalized object profile. When ``sigclip`` is set, pixels whose
    residual from the model exceeds ``sigclip`` times their noise are rejected
    as cosmic rays and the extraction is repeated ``niter`` times.

    Args:
        image: Sky-subtracted order image, shape ``(nspec, nspat)``.
        ivar: Inverse-variance image, same shape as ``image``.
        profile: Normalized per-row profile image, same shape as ``image``.
        mask: Optional good-pixel mask, same shape as ``image``.
        min_frac_use: Minimum used profile fraction for a valid pixel.
        sigclip: Cosmic-ray rejection threshold in sigma, or ``None`` to skip.
        niter: Maximum number of cosmic-ray rejection iterations.

    Returns:
        The :class:`OptimalExtraction`.
    """
    image = np.asarray(image, dtype=float)
    ivar = np.asarray(ivar, dtype=float)
    profile = np.asarray(profile, dtype=float)
    good = np.isfinite(image) & np.isfinite(ivar) & (ivar > 0) & np.isfinite(profile)
    good &= profile > 0
    if mask is not None:
        good &= np.asarray(mask, dtype=bool)

    cr_mask = np.zeros_like(good)
    flux, variance, ivar_out, spectrum_mask, frac_use, chi2 = _optimal_step(
        image, ivar, profile, good
    )

    if sigclip is not None:
        for _ in range(max(0, int(niter))):
            rejected = reject_cosmic_rays(
                image, ivar, profile, flux, good, sigclip=float(sigclip)
            )
            if not rejected.any():
                break
            good &= ~rejected
            cr_mask |= rejected
            flux, variance, ivar_out, spectrum_mask, frac_use, chi2 = _optimal_step(
                image, ivar, profile, good
            )

    spectrum_mask &= frac_use > float(min_frac_use)
    flux = np.where(spectrum_mask, flux, np.nan)
    variance = np.where(spectrum_mask, variance, np.nan)
    ivar_out = np.where(spectrum_mask, ivar_out, 0.0)
    return OptimalExtraction(
        flux=flux,
        var=variance,
        ivar=ivar_out,
        mask=spectrum_mask,
        frac_use=frac_use,
        chi2=chi2,
        cr_mask=cr_mask,
    )
